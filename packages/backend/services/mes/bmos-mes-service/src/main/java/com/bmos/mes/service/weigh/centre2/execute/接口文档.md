# 称量执行相关接口文档

## 1. 分页查询工单

- **URL**：`/api/app/mes/weigh/centre2/execute/ticket/page`
- **请求方式**：GET
- **请求参数**（WeighTicketPageDTO）：

| 字段名      | 类型   | 必填 | 说明           |
| ----------- | ------ | ---- | -------------- |
| pageNum     | int    | 是   | 当前页码       |
| pageSize    | int    | 是   | 每页条数       |
| orderBy     | string | 否   | 排序           |
| dir         | string | 否   | 排序方向       |
| orderSql    | string | 否   | 自定义多字段排序 |
| material    | string | 否   | 物料名称或编码 |
| centre      | string | 否   | 称量中心名称或编码 |
| ticketNo    | string | 否   | 工单号         |

- **返回值**（ResponseInfo<CommonPage<WeighTicketPageVO>>）：

| 字段名              | 类型   | 说明           |
| ------------------- | ------ | -------------- |
| id                  | Long   | 工单ID         |
| materialMergeCode   | String | 物料合并编码   |
| materialName        | String | 物料名称       |
| centreCode          | String | 称量中心编码   |
| centreName          | String | 称量中心名称   |
| ticketNo            | String | 工单号         |
| planDate            | LocalDate | 计划生产日期   |
| sendTime            | LocalDateTime | 下发日期   |
| completeTime        | LocalDateTime | 完成时间   |
| materialSpecification | String | 物料规格     |
| operator            | String | 操作人姓名     |
| unitId              | Long   | 单位ID         |
| unitName            | String | 单位名称       |
| weighCentreId       | Long   | 称量中心ID     |
| ticketWeighStatus   | Integer| 工单称量状态   |
| total               | int    | 总条数         |
| pageNum             | int    | 当前页码       |
| pageSize            | int    | 每页条数       |
| list                | List<WeighTicketPageVO> | 工单列表 |

- **请求示例**：

```json
{
  "pageNum": 1,
  "pageSize": 10,
  "material": "氯化钠",
  "centre": "中心A",
  "ticketNo": "GD20240501"
}
```

- **返回示例**：

```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "list": [
      {
        "id": 1001,
        "materialMergeCode": "M001",
        "materialName": "氯化钠",
        "centreCode": "C001",
        "centreName": "中心A",
        "ticketNo": "GD20240501",
        "planDate": "2024-05-01",
        "sendTime": "2024-04-30T11:00:00",
        "completeTime": null,
        "materialSpecification": "25kg/袋",
        "operator": "张三",
        "unitId": 1,
        "unitName": "kg",
        "weighCentreId": 10,
        "ticketWeighStatus": 1
      }
    ],
    "total": 1,
    "pageNum": 1,
    "pageSize": 10
  }
}
```

## 8. 保存称量记录

- **URL**：`/api/app/mes/weigh/centre2/execute/requirement/record`
- **请求方式**：POST
- **请求参数**（WeighRequirementRecordDTO）：

| 字段名      | 类型   | 必填 | 说明           |
| ----------- | ------ | ---- | -------------- |
| weighTicketRequirementId | Long | 是 | 称量需求ID |
| ticketId    | Long   | 否   | 工单id（余料称量时） |
| netWeight   | BigDecimal | 是 | 净重（kg）    |
| tareWeight  | BigDecimal | 否 | 皮重（kg）    |
| grossWeight | BigDecimal | 否 | 毛重（kg）    |
| weighFunc   | Integer| 否   | 称量功能类型   |
| weighType   | Integer| 否   | 称量类型       |
| unitId      | Long   | 否   | 单位ID        |
| deviceId    | Long   | 否   | 设备ID        |
| deviceName  | String | 否   | 设备名称      |
| deviceCode  | String | 否   | 设备编码      |
| storageId   | Long   | 否   | 仓库/库位ID   |

- **返回值**（ResponseInfo<TicketRequirementEnoughVO>）：

| 字段名              | 类型   | 说明           |
| ------------------- | ------ | -------------- |
| requirementEnough   | Boolean| 是否满足目标量 |
| outOddmentTargetEnough | Boolean | 是否超出余料目标量 |
| oddmentEnough       | Boolean| 是否进入余料称量 |
| weighRequirementRecordVOList | List<WeighRequirementRecordVO> | 当前需求/余料的称量记录 |

- **WeighRequirementRecordVO**：

| 字段名      | 类型   | 说明           |
| ----------- | ------ | -------------- |
| id          | Long   | 记录ID         |
| netWeight   | Double | 净重           |
| tareWeight  | Double | 皮重           |
| grossWeight | Double | 毛重           |
| unitName    | String | 单位名称       |
| weighUserId | String | 称量人ID       |
| weighTime   | Date   | 称量时间       |
| deviceName  | String | 设备名称       |
| deviceCode  | String | 设备编码       |
| signUser    | String | 签名用户       |
| signTime    | Date   | 签名时间       |
| signStatus  | Integer| 签名状态       |

- **请求示例**：

```json
{
  "weighTicketRequirementId": 2001,
  "netWeight": 25.0,
  "unitId": 1,
  "deviceName": "容器A"
}
```

- **返回示例**：

```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "requirementEnough": true,
    "outOddmentTargetEnough": false,
    "oddmentEnough": false,
    "weighRequirementRecordVOList": [
      {
        "id": 5001,
        "netWeight": 25.0,
        "unitName": "kg",
        "weighUserId": "u001",
        "weighTime": "2024-05-01T10:00:00",
        "deviceName": "容器A"
      }
    ]
  }
}
```
