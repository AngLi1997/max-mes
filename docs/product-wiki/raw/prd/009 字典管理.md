1. 权限：
    1. 操作权限
        1. 字典列表和数据列表中所有操作按钮有权限控制，由平台的操作权限功能支持；
2. 列表
    1. 页面初始化时，上方字典列表展示所有字典信息，选择某条字典信息后，下方字典数据展开，展示该字典所有的数据标签；
    2. 按钮展示规则
        1. 字典列表默认展示“新增字典”、“编辑”、“查看”、“删除”按钮；
        2. 数据列表展示“编辑”、“查看”、“删除”按钮；
        3. 所有按钮支持操作权限配置；
    3. 排序规则
        1. 字典列表和字典数据列表都以创建时间逆序排序；
    4. 字段说明

| **字典列表字段项** | **字段说明** | **固定（Y/N）** | **字段备注** |
| --- | --- | --- | --- |
| 字典名称 | 字典的名称，新增字典时手动输入 | Y |  |
| 字典编码 | 字典的编码，新增字典时手动输入 | Y |  |


| **数据列表字段项** | **字段说明** | **固定（Y/N）** | **字段备注** |
| --- | --- | --- | --- |
| 数据标签 | 字典包含的数据标签信息 | Y |  |
| 数据键值 | 字典数据标签对于的数据键值 | Y |  |


    5. 筛选规则

| **字典字段项** | **说明** |
| --- | --- |
| 字典名称 | 模糊查询 |
| 字典编码 | 模糊查询 |


| **数据字段项** | **说明** |
| --- | --- |
| 数据标签 | 模糊查询 |
| 数据键值 | 模糊查询 |


3. 功能
    1. 新增字典功能

<!-- 这是一张图片，ocr 内容为： -->

        1. 点击【新增字典】按钮，跳转至新增字典页面，录入字典信息（名称、编码），新增成功后，字典信息列表中增加对应的字典信息；记录新增字典信息的审计追踪信息；
            1. <font style="color:#DF2A3F;">点击【保存】按钮，提交时校验字典编码是否重复</font>，若已存在，则新增字典信息失败，给出提示：字典编码已存在；

            1. 点击【添加数据】按钮，弹出添加数据弹窗，输入数据标签和数据键值，确定后，该数据标签展示在数据列表中；
            2. 点击确定时，<font style="color:#DF2A3F;">校验字典中该数据键值是否重复</font>，若已存在，则添加数据失败，给出提示：字典数据已存在；

    2. 编辑
        1. 内置字典无法编辑，不展示编辑按钮；
        2. 选择字典信息，点击【编辑】按钮，进入字典信息编辑页面；编辑成功后，记录编辑字典信息的审计追踪信息；

    3. 查看
        1. 选择字典信息，点击【查看】按钮，进入查看字典信息页面，所有信息只能查看无法编辑保存；

        2. 点击确定时，<font style="color:#DF2A3F;">校验该字典中数据键值是否重复</font>，若已存在，则添加数据失败，给出提示：字典数据已存在；
