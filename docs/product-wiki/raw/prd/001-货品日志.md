##### 菜单
1. “货品日志”是“仓库查询”二级菜单下的三级菜单；菜单顺序由menu脚本配置；

##### 列表
1. 列表展示规则
    1. 货品日志列表为单列表默认交互；
    2. 页面初始化时，货品日志列表默认展示操作时间为最近30天的货品日志；
        1. 默认以日志的“操作时间”降序排列；
2. 字段说明

| **货品日志列表字段项** | **说明** |
| --- | --- |
| 序号 | 货品日志在当前页的序号 |
| 操作时间 | 操作时间，展示为年月日时分秒，yyyy-MM-dd hh:mm:ss |
| 操作类型 | 操作类型 |
| 具体操作 | 具体操作，来源为记录货品日志的操作 |
| 操作人员 | 操作人员，用户名称-账号 |
| 货品名称 | 货品名称，来源为操作的货品件所属货品信息 |
| 货品编码 | 货品编码（合并编码），来源为操作的货品件所属货品信息 |
| 货品批号 | 货品批号，来源为操作的货品件所属货品批次信息 |
| 货品件号 | 货品件号，来源为操作的货品件信息 |
| 预定量 | 货品件执行操作后的预定量 |
| 可用量 | 货品件执行操作后的可用量 |
| 单位 | 货品件的单位 |
| 货品状态 | 货品件的状态，有可用和不可用两种，货品批次过有效日期后转为不可用 |
| 有效日期 | 货品件的有效日期 |
| 产品名称 | 产品名称，来源为货品件在执行仓库发料操作时的领料单所属生产批次的产品信息 |
| 产品编码 | 产品编码（合并编码），来源为货品件在执行仓库发料操作时的领料单所属生产批次的产品信息 |
| 生产批号 | 生产批号，来源为货品件在执行仓库发料操作时的领料单所属生产批次 |
| 工艺名称 | 工艺名称，来源为货品件在执行仓库发料操作时的领料单所属生产批次的工艺信息 |
| 领料单 | 领料单号，来源为货品件在执行仓库发料操作时的领料单信息 |
| 货位名称 | 货位名称，来源为货品件执行操作后的货位信息 |
| 货位编码 | 货位编码，来源为货品件执行操作后的货位信息 |
| 所属位置 | 货位的所属位置，来源为货品件执行操作后的货位信息 |
| 供应商 | 货品件的供应商信息，来源为货品件的所属批次（货品） |
| 生产商 | 货品件的生产商信息，来源为货品件的所属批次（货品） |
| 原厂批号 | 原厂批号，来源为货品件的所属批次 |
| 备注 | 执行操作的备注信息 |
| 请验单号 | 请验单号，来源为货品件所属批次的最新检验信息，当前版本没有 |
| 报告单编号 | 报告单编号，来源为货品件所属批次的最新检验信息，当前版本没有对接检验，在货品批次直接输入 |
| 放行单编号 | 放行单编号，来源为货品件所属批次的最新检验信息，当前版本没有对接检验，在货品批次直接输入 |
| 检验信息 | 查看当前检验单号对应的检验详情，当前版本没有 |


3. 筛选规则
    1. 以列表内容进行筛选查询
    2. 筛选框输入内容，点击查询按钮后列表展示符合筛选条件的信息；

| 字段项 | 说明 |
| --- | --- |
| 货品信息 | <font style="color:rgb(8, 18, 34);background-color:rgb(252, 253, 255);">下拉选择为所选货品类型货品树；必须选到货品这一级；单选；</font> |
| 货品批号 | <font style="color:rgb(8, 18, 34);background-color:rgb(252, 253, 255);">级联货品信息；可以输入进行搜索的下拉选择框，考虑防抖请求时序控制</font> |
| 货品件号 | <font style="color:rgb(8, 18, 34);background-color:rgb(252, 253, 255);">级联货品批号；可以输入进行搜索的下拉选择框，考虑防抖请求时序控制</font> |
| 操作类型 | <font style="color:rgb(8, 18, 34);background-color:rgb(252, 253, 255);">对应列表中的“操作类型”字段；</font>   <font style="color:rgb(8, 18, 34);background-color:rgb(252, 253, 255);">来源为系统内置：入库、出库、盘点、新增</font> |
| 操作时间 | 下拉选择时间段 |
