##### 菜单
1. “物料日志”是“生产查询”二级菜单下的三级菜单；菜单顺序由menu脚本配置；

##### 列表
1. 列表展示规则
    1. 物料日志列表为单列表默认交互；
    2. 页面初始化时，物料日志列表默认展示操作时间为最近30天的物料日志；
        1. 默认以日志的“操作时间”降序排列；
2. 字段说明

| **物料日志列表字段项** | **说明** |
| --- | --- |
| 序号 | 物料日志在当前页的序号 |
| 操作时间 | 操作时间，展示为年月日时分秒，yyyy-MM-dd hh:mm:ss |
| 操作类型 | 操作类型 |
| 具体操作 | 具体操作，来源为记录物料日志的操作 |
| 操作人员 | 操作人员，用户名称-账号 |
| 物料名称 | 物料名称，来源为操作的物料件所属物料信息 |
| 物料编码 | 物料编码（合并编码），来源为操作的物料件所属物料信息 |
| 物料批号 | 物料批号，来源为操作的物料件所属物料批次信息 |
| 物料件号 | 物料件号，来源为操作的物料件信息 |
| 预定量 | 物料件执行操作后的预定量 |
| 可用量 | 物料件执行操作后的可用量 |
| 皮重 | 物料件称量操作的皮重 |
| 毛重 | 物料件称量操作的毛重 |
| 单位 | 物料件的单位 |
| 物料状态 | 物料件的状态，有可用和不可用两种，物料批次过有效日期后转为不可用 |
| 有效期至 | 物料件的有效期至 |
| 质量状态 | 产生物料日志时对应的物料批次质量状态（待验、合格、不合格、已取样、限制性放行） |
| 产品名称 | 产品名称，来源为物料件在执行操作时所属生产批次的产品信息 |
| 产品编码 | 产品编码（合并编码），来源为物料件在执行操作时所属生产批次的产品信息 |
| 生产批号 | 生产批号，来源为物料件在执行操作时所属生产批次 |
| 暂存货位 | 暂存货位名称，来源为物料件执行操作后的暂存货位信息 |
| 货位编码 | 暂存货位编码，来源为物料件执行操作后的暂存货位信息 |
| 所属位置 | 暂存货位的所属位置，来源为物料件执行操作后的货位信息 |
| 供应商 | 物料件的供应商信息，来源为物料件的所属批次（物料） |
| 生产商 | 物料件的生产商信息，来源为物料件的所属批次（物料） |
| 原始编码 | 原始编码，来源为物料件的所属批次 |
| 原厂批号 | 原厂批号，来源为物料件的所属批次 |
| 备注 | 执行操作的备注信息 |
| 请验单号 | 请验单号，来源为物料件所属批次的最新检验信息，当前版本没有检验，在物料管理功能输入 |
| 报告单编号 | 报告单编号，来源为物料件所属批次的最新检验信息，当前版本没有对接检验，在物料管理功能输入 |
| 检验信息 | 点击【查看】按钮，展示当前检验单号对应的检验详情，<br/>若请验单无检验结果，点击【查看】按钮提示请验单未收到检验结果。 |


3. 筛选规则
    1. 以列表内容进行筛选查询
    2. 筛选框输入内容，点击查询按钮后列表展示符合筛选条件的信息；

| **字段项** | **说明** |
| --- | --- |
| 物料类型 | <font style="color:rgb(8, 18, 34);background-color:rgb(252, 253, 255);">物料类型，来源为系统内置，可选“原辅包”或“中间品”</font> |
| 物料信息 | <font style="color:rgb(8, 18, 34);background-color:rgb(252, 253, 255);">级联物料类型选择框，下拉选择为所选物料类型物料树（展示分类/物料合并编码-物料名称）；必须选到物料这一级；单选；   </font><font style="color:rgb(8, 18, 34);background-color:rgb(252, 253, 255);">未选择物料类型时点击该下拉框提示请选择物料类型；</font> |
| 物料批号 | <font style="color:rgb(8, 18, 34);background-color:rgb(252, 253, 255);">级联物料信息；可以输入进行搜索的下拉选择框，考虑防抖请求时序控制</font> |
| 物料件号 | <font style="color:rgb(8, 18, 34);background-color:rgb(252, 253, 255);">级联物料批号；可以输入进行搜索的下拉选择框，考虑防抖请求时序控制</font> |
| 操作类型 | <font style="color:rgb(8, 18, 34);background-color:rgb(252, 253, 255);">对应列表中的“操作类型”字段；</font>   <font style="color:rgb(8, 18, 34);background-color:rgb(252, 253, 255);">来源为系统内置：入库、出库、盘点、新增、称量等</font> |
| 操作时间 | 下拉选择时间段 |
