###  需求详情
#### 编号规则 <font style="background:#F8CED3;color:#70000D">p0</font>
1. 权限：
    1. 操作权限：编号规则列表中所有操作按钮可以进行权限控制，由平台的操作权限功能支持；
2. 菜单：
    1. “编号规则”是“生产配置”一级菜单下的二级菜单，菜单顺序由菜单脚本处理；

##### 生产批号编号规则
<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2023/png/38732851/1702001256017-e883654a-f945-4787-9ae5-a9df39897949.png)

1. 列表
    1. 列表展示工艺配置功能中所有的工艺的生产批号规则，工艺未配置生产批号规则的展示为空；
    2. 按钮展示规则
        1. 生产批号规则列表默认展示“批量配置”和“编辑”按钮；
    3. 排序规则
        1. 生产批号规则列表以工艺创建时间逆序排序；
    4. 字段说明

| **列表字段项** | **字段说明** | **固定（Y/N）** | **字段备注** |
| --- | --- | --- | --- |
| 产品名称 | 产品的名称，通过工艺信息带出产品信息 | Y |  |
| 产品编码 | 产品的编码（合并编码），通过工艺信息带出产品信息 | Y |  |
| 工艺名称 | 工艺的名称，来源为工艺配置功能中的工艺信息 | Y | |
| 生产批号规则 | 工艺绑定的生产批号规则 | Y | |
| 规则编码 | 绑定生产批号规则的规则编码 | Y | |
| 操作 | 展示操作按钮 | Y | |


    5. 筛选规则

| **字段项** | **说明** |
| --- | --- |
| 产品名称 | 模糊查询 |
| 产品编码 | 模糊查询 |
| 工艺名称 | 模糊查询 |


2. 功能
    1. **编辑**

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2023/png/38732851/1702706119668-4f1bc006-5e09-4cfb-935a-2bcfac98b08d.png)

        1. 选择工艺信息点击【编辑】按钮，弹出编号规则弹窗，回显产品名称、产品编码和工艺名称，选择生产批号规则，可选范围为字典管理中内置的生产批号编号规则字典的数据，展示为“数据标签-数据键值”；确定后工艺绑定编号规则成功；
    2. **批量配置**

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2023/png/38732851/1702006604956-089533eb-5ef1-4084-976a-e45fac0cb189.png)

        1. 点击【批量配置】按钮，弹出批量配置弹窗；
        2. 第一步：选择生产批号编号规则（必选），可选范围为字典管理中内置的生产批号编号规则字典的数据，展示为“数据标签-数据键值”，选择后点击下一步进行工艺选择；

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2023/png/38732851/1702006953863-2724236c-783b-4a9b-aad7-44ea78edec2c.png)

        3. 第二步：选择工艺，展示为工艺树（产品分类-产品-工艺的层级展示），回显选择的生产批号规则；选择生产工艺，点击确定后，工艺批量配置编号规则成功；回到列表页，列表页刷新展示工艺绑定的编号规则；
            1. 工艺名称模糊查询；
            2. 点击上一步回到第一步选择编号规则；
