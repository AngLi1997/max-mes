#### 暂存间管理<font style="background:#F8CED3;color:#70000D">p0</font>
**需求描述：**

1. 暂存间信息与物料件绑定，管理车间的物料件信息；
2. 提供物料入库、物料退库、物料出库、物料移库、物料盘点等功能；
3. 暂存货位有权限控制，暂存间管理员只能操作有授权的暂存间物料；

        1. 点击确定后进行签名确认，弹出“接收人”和“递交人”签名弹窗；
        2. “接收人”不可更改，为当前网页端登录的用户，展示为用户名称-用户账号；
        3. “递交人”默认为空，带搜索的选择框，可选范围为拥有递交人权限码绑定角色的人员；
        4. 点击【确定】进行账号密码校验，校验通过后物料接收入库成功；当密码错误时，提示接收人密码错误或递交人密码错误，都错误时优先提示接收人密码错误；
    4. 同种物料类型下（原辅包或中间品）下同种物料的物料批次号不能重复；
        1. 若输入的物料批次号已存在，该物料批次的其他字段（物料批次的固定字段和物料自定义字段）回显所选批次信息，无法编辑；
    5. 物料接收时创建物料批次和物料件
        1. 物料批次
            1. 初始量、可用量、预定量和消耗量均为该批次的物料件的各物料量汇总，需考虑单位换算；
            2. 物料批次的单位默认为该物料（区分原辅包和中间品）绑定的单位信息；
        2. 物料件
            1. 物料件号默认生成，MES系统中所有物料件号不重复（不区分原辅包和中间品）；件号规则默认为正整数递增，最大位数为10位；生成时超过最大值后又从1开始生成；
            2. 初始量为默认为物料入库时的单件量，可用量默认为单件量，预定量默认为0，消耗量默认为0；
            3. 物料件的单位默认为物料接收时录入单件量对应的单位信息；
        3. <u>示例：比如物料绑定单位为kg，入库信息第1行输入1kg入库2件；第二行输入600g入库5件，最终物料批次创建后会有5kg库存；有7个物料件，分别为2个1kg和5个 600g库存。  </u>
    6. 物料接收时记录操作日志、物料日志、货位日志、签名日志
        1. 物料日志：每个物料件记录两条物料日志，操作类型为“入库”，具体操作分别为“物料接收-接收”和“物料接收-递交”，操作人员分别为对应的接收人和递交人；
        2. 货位日志：若接收时选择暂存货位，每个物料件记录两条货位日志，操作类型为“入库”，具体操作分别为“物料接收-接收”和“物料接收-递交”，操作人员分别为对应的接收人和递交人；物料量为对应物料件入库量；
        3. 操作日志：记录一条操作日志，操作类型：编辑；业务操作：物料接收；
        4. 签名日志：记录两条签名日志，签名动作：物料接收-接收、物料接收-递交；
