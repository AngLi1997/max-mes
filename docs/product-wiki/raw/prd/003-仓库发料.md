##### 权限：
    1. 操作权限
        1. 列表中所有操作按钮权限可通过平台的操作权限功能控制；

##### 菜单
    1. “仓库发料”是“仓库管理”二级菜单下的三级菜单；菜单顺序由menu脚本配置；

##### 列表
1. 列表展示规则
    1. 仓库发料列表为单列表默认交互；
    2. 页面初始化时，仓库发料列表默认展示所有待发料的领料计划信息；
        1. 默认以领料计划的“计划时间”降序排列；
2. 按钮展示规则
    1. 列表展示“发料”和“取消”按钮；
3. 分页规则
    1. 点击列表显示条数下拉选择框，选择对应列表展示列表信息条数，选定条数后，列表展示条数更新，分页栏分页页码更新；
    2. 点击分页栏页码，列表展示对应页码的信息，同时对应页码做选中状态；
    3. 点击左右箭头切换按钮或输入前往页码，列表切换至对应页信息，同时切换分页页码；
4. 字段说明

| **仓库发料列表字段项** | **说明** |
| --- | --- |
| 产品名称 | 产品名称，来源为该领料计划所属生产批次的产品信息 |
| 产品编码 | 产品编码，来源为该领料计划所属生产批次的产品信息 |
| 产品规格 | 产品规格，来源为该领料计划所属生产批次的产品信息 |
| 工艺名称 | 工艺名称，来源为该领料计划所属生产批次的工艺信息 |
| 生产批号 | 生产批号 |
| 领料单 | 领料单名称，来源为领料计划自动生成 |
| 计划人 | 1. 领料计划的计划人，来源为领料计划完成时计划人签名<br/>2. 展示为“用户名称-账号” |
| 计划时间 | 1. 领料计划的下发时间，来源为领料计划完成时的时间<br/>2. 展示为年月日时分秒，“yyyy-MM-dd hh:mm:ss” |
| 操作 | 展示操作按钮 |


5. 筛选规则
    1. 以列表内容进行筛选查询
    2. 筛选框输入内容，列表动态展示符合筛选条件的信息；

4. 完成仓库发料
    1. 签名校验

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2024/png/38732851/1712544082731-338d2fa2-01b6-4413-bad5-2b5a824ddf12.png)

        1. 点击【完成】按钮后进行签名确认，弹出“发料人”和“复核人”签名弹窗；
        2. “发料人”不可更改，为当前网页端登录的用户，展示为用户名称-用户账号；
        3. “复核人”默认为空，带搜索的选择框，<font style="color:#DF2A3F;">可选范围由权限码配置角色进行控制；</font>
        4. 点击【确定】进行账号密码校验，校验通过后批次发料成功；当密码错误时，提示发料人密码错误或复核人密码错误，都错误时优先提示发料人密码错误；
    2. 校验<font style="color:#DF2A3F;">（重要！）</font>
        1. 提交数据时校验每个批次发料量是否满足计划量，若批次发料量小于计划量，提示批次发料未完成，请继续添加；
        2. 提交数据时校验货品件是否生效，若货品件已失效，提示所选货品件已失效，请重新选择；
        3. 提交数据时校验货品批次的发料量大于该领料计划的预定量与货品批次的可用量之和时，不允许完成发料，提示货品批次xxx库存量无法满足其他领料计划，无法发料；（xxx为对应的货品批次）
        4. 提交数据时校验货品批次的发料量大于该领料计划的预定量与货品的可用量之和时，不允许完成发料，提示货品xxx库存量无法满足其他领料计划，无法发料；（xxx为对应的货品名称-合并编码）
    3. 各种量的变化
        1. 仓库中货品批次发料成功时，以下是各种量的变化；
            1. 货品件初始量不变，可用量减少，预定量不变，消耗量增加；货品件用尽（消耗）；
            2. 货品批次预定量减少，可用量根据发料量不变或减少（当发料量超过领料计划预定量时，可用量扣除超出部分），初始量不变，消耗量增加；货品批次下所有货品件用尽时，货品批次用尽；
            3. 货品预定量减少，可用量根据发料量不变或减少（当发料量超过领料计划预定量时，可用量扣除超出部分），初始量不变，消耗量增加；
    4. 货品发料时记录操作日志、货品日志、货位日志、签名日志
        1. 货品日志：每个货品件记录两条货品日志，操作类型为“出库”，具体操作分别为“货品出库-发料”和“货品出库-复核”，操作人员分别为对应的发料人和复核人；
        2. 货位日志：每个货品件记录两条货位日志，操作类型为“出库”，具体操作分别为“货品出库-发料”和“货品出库-复核”，操作人员分别为对应的发料人和复核人；货品量为货品件出库量；
        3. 操作日志：记录一条操作日志，操作类型：编辑；业务操作：批次发料；
        4. 签名日志：记录两条签名日志，签名动作：货品出库-发料、货品出库-复核；

###### 取消发料功能
<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2024/png/38732851/1712652266331-50b502ed-bf2f-4915-a2ca-a9c8aacc4cf7.png)

1. 仓库发料列表页，选择待发料的领料计划点击【取消】按钮，弹出取消发料确认签名弹窗，签名通过后，取消当前领料计划发料；
    1. 通知MES，领料计划已取消；
    2. 签名校验
        1. “取消人”不可更改，为当前网页端登录的用户，展示为用户名称-用户账号；
        2. “复核人”默认为空，带搜索的选择框，<font style="color:#DF2A3F;">可选范围由权限码配置角色进行控制；</font>
        3. 点击【确定】进行账号密码校验，校验通过后领料计划取消发料；当密码错误时，提示取消人密码错误或复核人密码错误，都错误时优先提示取消人密码错误；
    3. 各种量的变化
        1. 领料计划为批次量领料：
            1. 货品批次预定量减少，可用量增加，初始量不变，消耗量不变；改变的量为当领料计划预定的量（计划量）；
            2. 货品预定量减少，可用量增加，初始量不变，消耗量不变；改变的量为当领料计划预定的量（计划量）；
        2. 领料计划为物料量领料：
            1. 货品预定量减少，可用量增加，初始量不变，消耗量不变；改变的量为当领料计划预定的量（计划量）；
    4. 货品入库时记录操作日志、签名日志
        1. 操作日志：记录一条操作日志，操作类型：编辑；业务操作：取消发料；
        2. 签名日志：记录两条签名日志，签名动作：货品出库-取消、货品出库-复核；
