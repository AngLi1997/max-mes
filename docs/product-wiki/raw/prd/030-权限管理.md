#### 能够设定用户的密码强度和规则 
1. 管理员可在【实施配置-参数配置】中设定密码的强度和规则

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2023/png/2680527/1698204684975-bf245dd0-9dc2-4d08-ba87-53c84a2d52ee.png)

2. 密码规则
    1. **密码字符集**

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2023/png/2680527/1698213414422-444b3034-6c09-41aa-a1da-d4da361334bd.png)

        1. 选项：大写字符、小写字符、数字、其他字符
        2. 选择方式：多选
        3. 选择了密码字符集中的某一项后，用户在设置密码时，则必须要有这项字符，但不限制此项字符的个数
        4. eg.密码字符集选中了【大写字符、数字】，以下密码：T12&#（√） 、r43rr（×）、RTTW（×）R3et（√）、TT33R（√）
    2. **最小密码长度**

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2023/png/2680527/1698216646244-6506cf09-6a37-4908-89f3-234f5320c38e.png)

        1. 用户设置密码时，密码位数不能少于最小密码长度填写的数值；
        2. 若不填写，最小密码长度≥1即可；若填写必须满足最少位数≥填写数；
        3. eg.最小密码长度为6，用户在设置密码时密码位数不能少于6位
        4. 填写限制：范围在6-24内的正整数；
    3. **密码尝试次数**

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2023/png/2680527/1698217024880-7f6da4bb-f437-42fb-8b66-2d14b26c82c9.png)

        1. 密码连续输错的次数。若超过了此次数，用户账号变为密码锁定状态。
        2. 若不填写，则无限制
        3. 填写限制：范围在0-24内的正整数
    4. **历史密码个数**

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2023/png/2680527/1698218067137-a8db092c-13ce-495d-b7fa-c6481d35079e.png)

        1. 修改密码时，不能重复以前N次的密码；
        2. eg.若历史密码数为2，第一次密码为123，第二次为234，再次修改密码时，密码不能和123、234中的任何一个一致。第三次修改为456，再次修改时，密码不能和234、456中任何一个一致。
        3. 填写限制：范围在0-6内的正整数
    5. 密码有效期
        1. 密码有效的天数，密码有效期超期过后，用户可在登录时修改密码。
        2. 若不填写，则永久有效
        3. 填写显示：0-999内的正整数
        4. eg.密码有效期为365天，用户初次激活后开始计算，365天后，用户需在登录时修改密码，修改后的密码又有365天的有效期。

    3. 限制：所需删除的部门节点下**<font style="color:#DF2A3F;">无用户且无子部门</font>**
