##### MES应用管理

![](https://cdn.nlark.com/yuque/0/2024/png/38732851/1705401583163-ae9da2f4-23c0-498e-812d-ea698459fa9a.png)

1. 权限：
    1. 操作权限：应用管理列表中所有操作按钮可以通过平台的操作权限功能支持；
2. 菜单：
    1. “应用管理”是“系统配置”一级菜单下的二级菜单，菜单顺序由菜单脚本处理；
3. 展示说明：
    1. “应用管理”功能展示系统信息和应用信息，应用信息展示为最新上传的应用版本；
4. 按钮说明：
    1. 应用信息中展示“发布”、“历史”、“上传”和“查看更多”按钮
        1. 应用为待发布状态时，发布按钮展示为可点击状态；
        2. 应用为已发布状态时，发布按钮展示为不可点击状态；
5. 字段说明：

| **字段项** | **字段说明** | **固定（Y/N）** | **字段备注** |
| --- | --- | --- | --- |
| 系统版本 | 系统的版本号 | Y |  |
| 系统当前时间 | 系统所在服务器的时间，展示为“yyyy-MM-dd hh:mm:ss” | Y |  |
| 应用版本 | 应用的版本号 | Y |  |
| 状态 | 应用的发布状态， | Y | |
| 发布人 | 应用的发布人，展示为“用户名称-账号”，应用未发布时发布人展示为“-” | Y | |
| 发布时间 | 应用的发布时间，展示为“yyyy-MM-dd hh:mm:ss” | Y | |
| 说明 | 应用上传时的说明信息 | Y | |


6. 应用状态

| **应用状态** | **状态说明** | **前置操作** |
| --- | --- | --- |
| 待发布 | 应用处于待发布状态，可以进行发布操作 | 上传的应用，处于发布 |
| 已发布 | 应用处于已发布状态，可以用于应用下载和更新 | 生产计划发起审批，状态由“编辑”转为“审批中”状态 |
| 已停用 | 应用处于已停用状态， | 处于已发布状态的应用，当其他版本应用发布时，由已发布状态转为已停用状态 |
| 已弃用 | 生产计划为不可用状态 | 生产计划作废 |


7. 功能
    1. 应用上传
