##### 权限
    1. 操作权限
        1. 列表中所有操作按钮权限可通过平台的操作权限功能控制；

##### 菜单
    1. “货品管理”是“仓库管理”二级菜单下的三级菜单；菜单顺序由menu脚本配置；

##### 左侧树
    1. <font style="color:rgb(38, 38, 38);">左侧树为货品树，来源为货品信息功能，信息结构包括货品分类和分类下的货品信息；</font>
    2. 进入页面，货位树默认展示根节点及二级分类，展示“合并编码-货品名称”；
    3. 以合并编码升序排序；

##### 列表
1. 列表展示规则
    1. 货品库存列表和货品批次列表为双列表默认交互；

[页面组件](https://bmos.yuque.com/bp7n97/tx8g07/auyyyms5vfrg3a9h#PwO1v)

    2. 货品库存列表
        1. 页面初始化时，货品库存列表默认展示全部货品的库存信息，选择左侧分类树某个货品时，货品库存列表展示对应货品的库存信息；
        2. 默认以货品的“合并编码”升序排列；
    3. 货品批次列表
        1. 初始化时，货品批次列表默认为空，选择上方货品库存列表某个货品时，货品批次列表展示对应货品的货品批次信息（历史批次也要展示）；
        2. 默认以货品批次的“创建时间”降序排序；
2. 按钮展示规则
    1. 货品批次列表展示“新增批次”、“物料件”、“编辑”、“查看”按钮；、
    2. 货品件列表展示“新增货品件”按钮；
3. 分页规则
    1. 见设计规范
4. 字段说明

| --- | --- |
| 货品名称 | 货品的名称 |
| 货品编码 | 货品的编码，展示为合并编码 |
| 货品规格 | 货品的规格 |
| 可用量 | 货品的可用量 |
| 预定量 | 货品的预定量 |
| 单位 | 货品的单位 |
| 件数 | 货品批次在当前货位中的未用尽的货品件数量; |


| **货品批次列表字段项** | **说明** |
| --- | --- |
| 货品批号 | 货品批次号 |
| 可用量 | 货品批次的可用量 |
| 预定量 | 货品批次的预定量 |
| 单位 | 货品批次的单位 |
| 操作 | 展示操作按钮 |




5. 筛选规则
    1. 以左侧树或列表内容进行筛选查询
    2. 筛选框输入内容，左侧树或列表动态展示符合筛选条件的信息；

##### 功能
###### 新增批次功能
<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2024/png/38732851/1712038026163-0291939f-d233-46bb-aa85-34fc5e19ec73.png)

1. 点击【新增批次】按钮，弹出新增货品批次弹窗，新建批次，货品批次列表中增加该货品批次；记录新增货品批次的审计追踪信息；
    1. 若选择上方货品库存列表中某条货品信息，再点击【新增批次】按钮，弹窗中货品信息（名称、编码、规格）字段将直接回显该条数据；
    2. 签名校验

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2024/png/38732851/1712028557826-eae5aa71-d33f-4a2c-8b81-357972491455.png)

        1. 点击确定后进行签名确认，弹出“操作人”签名弹窗；
        2. “操作人”不可更改，为当前网页端登录的用户，展示为用户名称-用户账号； 
        3. 点击【确定】进行账号密码校验，校验通过后货品批次新增成功；当密码错误时，提示操作人密码错误；
    3. 同种货品的货品批次号不能重复；
        1. 若货品批次号已存在，签名确认后校验批号是否重复，若重复则提示该货品批次已存在，不能创建相同的货品批次；
    4. 创建货品批次
        1. 货品批次
            1. 初始量、可用量、预定量和消耗量均0；
            2. 货品批次的单位默认为该货品绑定的单位信息；
    5. 新增货品批次时记录操作日志、签名日志
        1. 操作日志：记录1条操作日志，操作类型：新增；业务操作：新增货品批次；
        2. 签名日志：记录1条签名日志，签名动作：新增货品批次；

###### 新增货品件功能

1. 选择货品批次点击【货品件】按钮进入查看批次货品件页面，展示该货品批次的货品件信息；

| **货品件列表字段项** | **说明** |
| --- | --- |
| 货品名称 | 货品名称，货品件对应的货品名称 |
| 货品编码 | 货品编码，货品件对应的货品编码，展示为合并编码 |
| 货品规格 | 货品规格，货品件对应的货品规格 |
| 货品批号 | 货品批次号，货品件的批次号 |
| 货品件号 | 货品件号，来源为货品入库/新增时创建 |
| 物料量 | 货品件的库存量，对应货品批次的“可用量”和“预定量”求和； |
| 单位 | 货品件的单位； |
| 货位 | 货品件的货位信息，展示为货位编码-货位名称 |


2. 新增货品件

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2024/png/38732851/1712481199454-fe6a768b-c676-46d4-909f-c5129c73cc48.png)

    1. 点击【新增货品件】按钮，弹出新增货品件弹窗，回显货品批次，输入要新增的货品件信息，批量创建；记录新增货品批次的审计追踪信息；

| **表单项** | **字段说明** | **必填（Y/N）** | **校验** | **字段备注** |
| --- | --- | --- | --- | --- |
| 单件量 | 货品件的单件量 | Y | 正数，整数部分最多为10位，小数位数最多为9位， |  |
| 单位 | 货品件的单位，手动选择 | Y |  |  |
| 件数 | 新增的货品件数 | Y | 正整数，[1,99] | |
| 货位 | 货位信息，手动选择 | Y | | |


    2. 批量创建货品件
        1. 货品件号默认生成，WMS系统中所有货品件号不重复；件号规则默认为正整数递增，最大位数为10位；生成时超过最大值后又从1开始生成；
        2. 货品件初始量为新增货品件时输入的初始量，可用量与初始量相等，预定量默认为0，消耗量默认为0；
        3. 货品件的单位默认为新增货品件时选择的单位信息；
        4. 货品批次的初始量、可用量、预定量和消耗量根据批次下的货品件各量和单位自动换算更新；
        5. 货品库存的初始量、可用量、预定量和消耗量根据对应货品批次的各量和单位自动换算更新；
    3. 签名校验

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2024/png/38732851/1712049736628-d1ea2baa-8d4e-46c3-98ae-2fef98aeaf11.png)

        1. 点击确定后进行签名确认，弹出“操作人”签名弹窗；
        2. “操作人”不可更改，为当前网页端登录的用户，展示为用户名称-用户账号； 
        3. 点击【确定】进行账号密码校验，校验通过后货品件新增成功；当密码错误时，提示操作人密码错误；
    1. 新增货品件时记录操作日志、货品日志、签名日志
        1. 货品日志：每个货品件记录1条货品日志：操作类型为“新增”，具体操作分别为“新增货品”；
        2. 操作日志：记录一条操作日志，操作类型：新增；业务操作：新增货品；
        3. 签名日志：记录一条签名日志，签名动作：新增货品；
