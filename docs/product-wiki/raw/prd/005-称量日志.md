##### 菜单
1. “称量日志”是“生产查询”二级菜单下的三级菜单；菜单顺序由menu脚本配置；

##### 列表
1. 列表展示规则
    1. 称量日志列表为单列表默认交互；
    2. 页面初始化时，列表默认展示近30日的称量日志；
        1. 默认以日志的“操作时间”降序排列；
2. 字段说明

| **称量日志列表字段项** | **说明** |
| --- | --- |
| 物料件号 | 物料件号，称量产生的物料件 |
| 净重 | 称量物料件的净重，来源为称量信息 |
| 皮重 | 称量物料件的皮重，来源为称量信息 |
| 毛重 | 称量物料件的毛重，来源为称量信息 |
| 单位 | 物料件的单位 |
| 称量类型 | 称量类型，<font style="color:rgb(8, 18, 34);background-color:rgb(252, 253, 255);">来源为不同的称量操作：配料称量、余料称量、产出称量、拆包称量等</font> |
| 称量人 | 称量人，展示为“用户名称-账号”； |
| 复核人 | 复核人，展示为“用户名称-账号”； |
| 称量时间 | 称量时间，展示为年月日时分秒，yyyy-MM-dd hh:mm:ss |
| 物料名称 | 物料名称，来源为称量物料件所属物料信息 |
| 物料编码 | 物料编码（合并编码），来源为称量物料件所属物料信息 |
| 物料批号 | 物料批号，来源为称量物料件所属物料批次信息 |
| 设备名称 | 称量设备名称，来源为称量信息 |
| 设备编号 | 称量设备编号，来源为称量信息 |
| 校准状态 | 秤具的校准状态 |
| 校准效期 | 秤具的校准有效期 |
| 产品名称 | 产品名称，来源为称量操作所属生产批次的产品信息 |
| 产品编码 | 产品编码（合并编码），来源为称量操作所属生产批次的产品信息 |
| 生产批号 | 生产批号，来源为称量操作所属生产批次 |


3. 筛选规则
    1. 以列表内容进行筛选查询
    2. 筛选框输入内容，点击查询按钮后列表展示符合筛选条件的信息；

| **字段项** | **说明** |
| --- | --- |
| 物料类型 | <font style="color:rgb(8, 18, 34);background-color:rgb(252, 253, 255);">可选原辅包或中间品；对应原辅包信息和中间品信息</font> |
| 物料信息 | <font style="color:rgb(8, 18, 34);background-color:rgb(252, 253, 255);">级联物料类型选择框，下拉选择为所选物料类型物料树；必须选到物料这一级；单选；</font>   <font style="color:rgb(8, 18, 34);background-color:rgb(252, 253, 255);">未选择物料类型时点击该下拉框提示请选择物料类型；</font> |
| 物料批号 | <font style="color:rgb(8, 18, 34);background-color:rgb(252, 253, 255);">输入物料批号进行模糊搜索</font> |
| 物料件号 | <font style="color:rgb(8, 18, 34);background-color:rgb(252, 253, 255);">输入物料件号进行模糊搜索</font> |
| 称量类型 | <font style="color:rgb(8, 18, 34);background-color:rgb(252, 253, 255);">对应列表中的“称量类型”字段；</font>   <font style="color:rgb(8, 18, 34);background-color:rgb(252, 253, 255);">来源为系统内置：配料称量、余料称量、产出称量、拆包称量等</font> |
| 秤具信息 | <font style="color:rgb(8, 18, 34);background-color:rgb(252, 253, 255);">输入设备名称/设备编号进行模糊搜索</font> |
| 产品信息 | <font style="color:rgb(8, 18, 34);background-color:rgb(252, 253, 255);">输入产品名称/合并编码进行模糊搜索</font> |
| 生产批号 | <font style="color:rgb(8, 18, 34);background-color:rgb(252, 253, 255);">输入生产批号进行模糊搜索</font> |
| 称量时间 | <font style="color:rgb(8, 18, 34);background-color:rgb(252, 253, 255);">下拉选择时间段，筛选对应时间段内的称量日志</font> |
