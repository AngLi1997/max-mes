#### 暂存间配置<font style="background:#F8CED3;color:#70000D">p0</font>
**需求描述：**

1. 期望提供功能维护和管理暂存间信息；
2. 暂存间信息有权限控制，只有拥有对应暂存间权限的人员才能操作暂存间中的物料；
3. 暂存间信息与物料件绑定，管理车间的物料件信息；

**功能设计：**

1. 权限：
    1. 数据权限
        1. 暂存货位进行部门授权，用户进行暂存间配置功能只展示有对应数据权限的暂存间货位
    2. 操作权限
        1. 分类树（存储区域）、暂存货位列表中所有操作按钮权限可通过平台的操作权限功能控制；
2. 菜单
    1. “暂存间配置”是“生产配置”二级菜单下的三级菜单；菜单顺序由menu脚本配置；
3. 左侧树
    1. <font style="color:rgb(38, 38, 38);">左侧树为自定义分类树，配置存储区域信息；</font>

            3. 若分类下不存在下级分类或存储货位，该分类允许删除；

1. 列表
    1. 列表展示规则
        1. 页面初始化时，存储货位列表默认展示全部存储货位，点击左侧分类树某条数据时，存储货位列表展示对应分类及下级分类的存储货位；
        2. 存储货位列表默认展示20条数据；
        3. 默认以存储货位的“货位编码”升序排列；
    2. 按钮展示规则
        1. 原辅包列表展示“新增”、“查看”、“编辑”、“启用/停用”、“删除”、“数据权限”按钮；
        2. 停用状态产品展示：“查看”、“编辑”、“数据权限”、“删除”；
        3. 启用状态产品展示：“查看”、“数据权限”
    3. 分页规则
        1. 点击列表显示条数下拉选择框，选择对应列表展示列表信息条数，选定条数后，列表展示条数更新，分页栏分页页码更新；
        2. 点击分页栏页码，列表展示对应页码的信息，同时对应页码做选中状态；
        3. 点击左右箭头切换按钮或输入前往页码，列表切换至对应页信息，同时切换分页页码；
    4. 字段说明

| 字段项 | 说明 |
| --- | --- |
| 暂存货位 | 暂存货位名称，新增/编辑暂存货位时手动输入 |
| 货位编码 | 暂存货位的编码，新增/编辑暂存货位时手动输入， |
| 所属区域 | 暂存货位所属的分类信息，多级分类以“/”分隔，如图； |
| 启停 | 暂存货位的启停状态，可以进行启用/停用操作 |
| 备注 | 暂存货位的备注信息，新增/编辑暂存货位时手动输入 |
| 操作 | 展示操作按钮 |


    5. 筛选规则
        1. 以左侧树或列表内容进行筛选查询
        2. 筛选框输入内容，左侧树或列表动态展示符合筛选条件的信息；

| 字段项 | 说明 |
| --- | --- |
| 分类 | 左侧树（存储区域） ，模糊查询 |
| 名称 | 暂存货位，模糊查询 |
| 编码 | 货位编码模糊查询 |


2. 功能
    1. **新增暂存货位功能**
        1. 点击【新增】按钮，弹出新增暂存货位弹窗，新增成功后，暂存货位列表中增加该暂存货位，暂存货位启停状态默认为停用状态；记录新增暂存货位的审计追踪信息；
            1. 若点击左侧分类树某条数据，再点击【新增】按钮，弹窗中分类（所属区域）字段将直接回显该条数据；
            2. 提交时校验货位编码是否重复，若已存在该货位编码，新增暂存货位失败，提示货位编码已存在；

    2. **暂存货位编辑功能**
        1. 选择“停用”状态的暂存货位点击【编辑】按钮，弹出编辑暂存货位弹窗，回显暂存货位信息，编辑成功后，记录编辑暂存货位的审计追踪信息；
            1. 提交时校验货位编码是否重复，若已存在该货位编码，编辑暂存货位失败，提示货位编码已存在；

    1. **暂存货位启停**
        1. 暂存货位启用
            1. 暂存货位为“停用”状态：点击【启停】开关，弹窗提示是否启用该暂存货位，确认后，该暂存货位的状态变更为“启用”状态；记录启用暂存货位的审计追踪信息；
        2. 暂存货位停用
            1. 暂存货位为“启用”状态：点击【启停】开关，弹窗提示是否停用该暂存货位，确认后，该暂存货位的状态变更为“停用”状态；记录停用暂存货位的审计追踪信息；
                1. 校验：若暂存货位中存在物料件，无法停用该暂存货位，提示暂存货位中存在物料件，不允许停用；
    2. **暂存货位查看**
        1. 选择暂存货位点击【查看】按钮，弹窗展示暂存货位信息；
    3. **数据权限功能**
        1. 点击【数据权限】按钮，进入数据权限弹窗，勾选部门信息，确认后，暂存货位和部门信息绑定；
        2. 部门树展示所有的部门信息；勾选部门节点，选中当前部门节点和上级部门节点，下级部门节点不会选中；
        3. 取消勾选部门节点，所选部门节点和下级部门节点取消勾选；
        4. 一条暂存货位数据可以属于多个部门信息；

            1. 删除校验：若该暂存货位已产生货位日志，无法删除该暂存货位，提示暂存货位已产生货位日志，无法删除；
