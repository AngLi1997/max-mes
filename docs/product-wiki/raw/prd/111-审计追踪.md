## 1. 背景介绍
### 1.1 需求背景
> <font style="color:#000000;">       </font>依据生物制药行业企业GMP法规要求，支持用户订单号→包装批号→生产批号→投浆批号全流程生产质量、生产资源追溯，并支持以生产资源唯一识别码（物料批号、设备编码等），追溯该生产资源在生产活动中的流转情况及使用情况，满足用户对生产过程中的质量监管、流程追溯、资源协调要求。
>

### 1.2 业务场景
| **场景/商业模式** | **业务价值** |
| --- | --- |
| 质量追溯 | 提供以批次维度，展示批次生产中审核信息、检验信息及偏差信息，满足QA/QC产品放行、质量监管需求 |
| 产品追溯 | 整合完整生产批次生产资源流转、使用信息 |
| 物料查询 | 提供以物料批次维度，展示物料批流转、使用信息 |
