##### 权限：
    1. 数据权限
        1. 货位进行部门授权，用户进行货位配置功能只展示有对应数据权限的货位
    2. 操作权限
        1. 分类树（存储区域）、货位列表中所有操作按钮权限可通过平台的操作权限功能控制；

##### 菜单
    3. “货位配置”是“仓库配置”二级菜单下的三级菜单；菜单顺序由menu脚本配置；

            3. 若分类下不存在下级分类或存储货位，该分类允许删除；

##### 列表
    1. 列表展示规则
        1. 页面初始化时，存储货位列表默认展示全部存储货位，点击左侧分类树某条数据时，存储货位列表展示对应分类及下级分类的存储货位；
        2. 存储货位列表默认展示20条数据；
        3. 默认以存储货位的“货位编码”升序排列；
    2. 按钮展示规则
        1. 货位列表展示“新增”、“查看”、“编辑”、“启用/停用”、“删除”、“数据权限”按钮；
        2. 停用状态产品展示：“查看”、“编辑”、“数据权限”、“删除”；
        3. 启用状态产品展示：“查看”、“数据权限”
    3. 分页规则
        1. 点击列表显示条数下拉选择框，选择对应列表展示列表信息条数，选定条数后，列表展示条数更新，分页栏分页页码更新；
        2. 点击分页栏页码，列表展示对应页码的信息，同时对应页码做选中状态；
        3. 点击左右箭头切换按钮或输入前往页码，列表切换至对应页信息，同时切换分页页码；
    4. 字段说明

| 字段项 | 说明 |
| --- | --- |
| 货位 | 货位名称，新增/编辑货位时手动输入 |
| 货位编码 | 货位的编码，新增/编辑货位时手动输入， |
| 所属区域 | 货位所属的分类信息，多级分类以“/”分隔，如图； |
| 启停 | 货位的启停状态，可以进行启用/停用操作 |
| 备注 | 货位的备注信息，新增/编辑货位时手动输入 |
| 操作 | 展示操作按钮 |


    5. 筛选规则
        1. 以左侧树或列表内容进行筛选查询
        2. 筛选框输入内容，左侧树或列表动态展示符合筛选条件的信息；

| 字段项 | 说明 |
| --- | --- |
| 分类 | 左侧树（存储区域） ，模糊查询 |
| 名称 | 货位，模糊查询 |
| 编码 | 货位编码模糊查询 |


##### 功能
###### 新增货位功能
    1. 点击【新增】按钮，弹出新增货位弹窗，新增成功后，货位列表中增加该货位，货位启停状态默认为停用状态；记录新增货位的审计追踪信息；
        1. 若点击左侧分类树某条数据，再点击【新增】按钮，弹窗中分类（所属区域）字段将直接回显该条数据；
        2. 提交时校验货位编码是否重复，若已存在该货位编码，新增货位失败，提示货位编码已存在；

###### 货位编辑功能
    1. 选择“停用”状态的货位点击【编辑】按钮，弹出编辑货位弹窗，回显货位信息，编辑成功后，记录编辑货位的审计追踪信息；
        1. 提交时校验货位编码是否重复，若已存在该货位编码，新增货位失败，提示货位编码已存在；

###### 货位启停
    1. 货位启用
        1. 货位为“停用”状态：点击【启停】开关，弹窗提示是否启用该货位，确认后，该货位的状态变更为“启用”状态；记录启用货位的审计追踪信息；
    2. 货位停用
        1. 货位为“启用”状态：点击【启停】开关，弹窗提示是否停用该货位，确认后，该货位的状态变更为“停用”状态；记录停用货位的审计追踪信息；
            1. 校验：若货位中存在物料件，无法停用该货位，提示货位中存在物料件，不允许停用；

###### 货位查看
    1. 选择货位点击【查看】按钮，弹窗展示货位信息；

###### 数据权限功能
    1. 点击【数据权限】按钮，进入数据权限弹窗，勾选部门信息，确认后，货位和部门信息绑定；
    2. 部门树展示所有的部门信息；勾选部门节点，选中当前部门节点和上级部门节点，下级部门节点不会选中；
    3. 取消勾选部门节点，所选部门节点和下级部门节点取消勾选；
    4. 一条货位数据可以属于多个部门信息；

###### 货位删除
    1. 选择“停用”状态的货位点击【删除】按钮，弹窗提示是否删除该货位，确认后，货位信息删除成功；
        1. 删除校验：若该货位已产生货位日志，无法删除该货位，提示货位已产生货位日志，无法删除；
