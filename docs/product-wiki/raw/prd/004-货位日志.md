## 变更记录
[此处为语雀卡片，点击链接查看](about:blank#OnTZc)

#### 货位日志
##### 菜单
1. “货位日志”是“生产查询”二级菜单下的三级菜单；菜单顺序由menu脚本配置；

##### 左侧树
    1. <font style="color:rgb(38, 38, 38);">左侧树为货位树，来源为货位配置功能，信息结构包括存储区域（分类）及区域下的货位信息；</font>
    2. 进入页面，货位树默认展示根节点及二级分类；
        1. <font style="color:rgb(38, 38, 38);">货位需展示“货位编码-货位名称”；</font>
        2. <font style="color:rgb(223, 42, 63);">排序：存储区域以分类节点创建时间升序排序，货位以货位编码升序排序；</font>

##### 列表
1. 列表展示规则
    1. 货位日志列表为单列表默认交互；
    2. 页面初始化时，货位日志列表默认展示操作时间为最近30天的货位日志；
        1. 默认以日志的“操作时间”降序排列；
2. 字段说明

| **货位日志列表字段项** | **说明** |
| --- | --- |
| 物料件号 | 物料件号，来源为操作的物料件信息 |
| 物料量 | 物料件执行操作时物料件的改变量 |
| 单位 | 物料件的单位，执行操作时物料件改变量对应的单位 |
| 操作时间 | 操作时间，展示为年月日时分秒，yyyy-MM-dd hh:mm:ss |
| 操作类型 | 操作类型,<font style="color:rgb(8, 18, 34);background-color:rgb(252, 253, 255);">来源为系统内置：入库、出库、盘增、盘减、新增</font> |
| 具体操作 | 具体操作，来源为记录货位日志的操作 |
| 操作人员 | 操作人员，用户名称-账号 |
| 货位名称 | 暂存货位名称，来源为物料件执行操作的暂存货位信息 |
| 货位编码 | 暂存货位编码，来源为物料件执行操作的暂存货位信息 |
| 所属位置 | 暂存货位的所属位置，来源为物料件执行操作后的暂存货位信息 |
| 物料名称 | 物料名称，来源为操作的物料件所属物料信息 |
| 物料编码 | 物料编码（合并编码），来源为操作的物料件所属物料信息 |
| 物料批号 | 物料批号，来源为操作的物料件所属物料批次信息 |
| 产品名称 | 产品名称，来源为物料件在执行仓库发料操作时的领料单所属生产批次的产品信息 |
| 产品编码 | 产品编码（合并编码），来源为物料件在执行仓库发料操作时的领料单所属生产批次的产品信息 |
| 生产批号 | 生产批号，来源为物料件在执行仓库发料操作时的领料单所属生产批次 |
| 备注 | 执行操作的备注信息 |


3. 筛选规则
    1. 以左侧树和列表内容进行筛选查询
    2. 筛选框输入内容，点击查询按钮后列表展示符合筛选条件的信息；

| **字段项** | **说明** |
| --- | --- |
| 货位信息 | 左侧树（存储区域） ，模糊查询 |
| 物料信息 | <font style="color:rgb(8, 18, 34);background-color:rgb(252, 253, 255);">输入物料名称或物料合并编码进行模糊搜索</font> |
| 物料批号 | <font style="color:rgb(8, 18, 34);background-color:rgb(252, 253, 255);">输入物料批号进行模糊搜索</font> |
| 物料件号 | <font style="color:rgb(8, 18, 34);background-color:rgb(252, 253, 255);">输入物料件号进行模糊搜索</font> |
| 操作类型 | <font style="color:rgb(8, 18, 34);background-color:rgb(252, 253, 255);">对应列表中的“操作类型”字段；</font>   <font style="color:rgb(8, 18, 34);background-color:rgb(252, 253, 255);">来源为系统内置：入库、出库、盘增、盘减、</font>~~<font style="color:rgb(8, 18, 34);background-color:rgb(252, 253, 255);">新增</font>~~ |
| 产品信息 | <font style="color:rgb(8, 18, 34);background-color:rgb(252, 253, 255);">手动选择，产品树只能选择产品信息节点，展示合并编码-产品名称</font> |
| 生产批号 | <font style="color:rgb(8, 18, 34);background-color:rgb(252, 253, 255);">输入生产批号进行模糊搜索</font> |
| 操作时间 | <font style="color:rgb(8, 18, 34);background-color:rgb(252, 253, 255);">下拉选择时间段，筛选对应时间段内的货位日志</font> |
