###  需求详情
#### 生产历史 <font style="background:#F8CED3;color:#70000D">p0</font>

1. 权限：
    1. 操作权限：生产历史列表中所有操作按钮有权限控制，由平台的操作权限功能支持；
    2. 数据权限：生产历史列表以生产批次的工艺绑定的部门数据权限，用户只能看到所属部门绑定的工艺生产批次；
2. 菜单：
    1. “生产历史”是“生产查询”一级菜单下的二级菜单，菜单顺序由菜单脚本处理；
3. 左侧树
    1. 左侧树为产品信息树，与工艺配置功能相同；来源为产品信息功能，信息结构包括产品分类及分类下的产品信息；
    2. 进入页面，产品树默认展示根节点及二级分类；
    3. 产品信息树选择分类或产品信息，右侧生产历史列表展示该分类或产品信息下所有的生产历史批次；
4. 列表
    1. 生产历史列表展示已结束的生产批次；
    2. 按钮展示规则
        1. 生产历史列表展示“预览打印”和“操作历史”按钮；
    3. 排序规则
        1. 生产历史列表默认以生产开始时间逆序排序；
    4. 字段说明

| **列表字段项** | **字段说明** | **固定（Y/N）** | **字段备注** |
| --- | --- | --- | --- |
| 产品名称 | 产品的名称 | Y |  |
| 产品编码 | 产品的编码（合并编码） | Y |  |
| 产品规格 | 产品的规格 | Y | |
| 生产批号 | 计划的生产批号 | Y | |
| 工艺名称 | 该生产批次的工艺名称 | Y | |
| 生产开始时间 | 该生产批次的生产开始时间（生产前确认的时间） | Y | |
| 生产结束时间 | 该生产批次的生产结束时间 | Y | |
| 状态 | 该生产批次的状态，正常生产结束为“已完成”，通过生产终止功能结束为“终止” | Y | |
| 操作 | 展示操作按钮 | Y | |


    5. 筛选规则

| **字段项** | **说明** |
| --- | --- |
| 产品信息 | 左侧树，模糊查询，对产品树的产品分类和产品信息进行筛选 |
| 生产批号 | 模糊查询 |
| 工艺名称 | 模糊查询 |


5. 功能
    1. 预览打印
        1. 选择生产批次点击【预览打印】按钮，弹出记录预览弹窗，展示该生产批次的记录文件；

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2023/png/38732851/1702707328217-c7c65de0-f84c-4dc2-8bd9-06afda519bc1.png)

            1. 生产批次所有归档项按工艺配置中归档顺序拼接；
            2. 记录复制产生的复制页按顺序拼接；
            3. 取证图片跟随在步骤配置的记录项后（区分复制页）；
        2. 点击【打印】按钮，处理记录样式，调用浏览器打印功能；
            1. 处理组件样式，表格单元格中只有一个基础组件时，去除组件样式后不添加下划线；非单元格中的组件或单元格中有多个组件或文字时，去除组件样式后在内容下添加下划线；
            2. 处理图片样式，取证图片一张图单独一页；

        1. 选择生产批次点击【操作历史】按钮，弹出操作历史弹窗，展示该生产批次的记录预览和打印历史记录；
