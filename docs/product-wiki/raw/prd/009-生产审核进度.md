###  需求详情
#### 生产审核进度 
<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2024/png/38732851/1723690743079-48282614-a333-4aa7-9106-e13f95413544.png)

1. 权限：
    1. 数据权限：生产审核进度列表有生产批次的工艺绑定的部门数据权限，用户只能看到所属部门绑定的工艺生产批次；
2. 菜单：
    1. “生产审核进度”是“生产查询”二级菜单下的三级菜单，菜单顺序由菜单脚本处理；
3. 左侧树
    1. 左侧树为产品信息树，与工艺配置功能相同；来源为产品信息功能，信息结构包括产品分类及分类下的产品信息；
    2. 进入页面，产品树默认展示根节点及二级分类；
    3. 产品信息树选择分类或产品信息，右侧生产审核进度列表展示该分类或产品信息下<font style="color:#DF2A3F;"></font>的生产批次审核进度批次；
4. 列表
    1. 生产审核进度列表展示<font style="color:#DF2A3F;">进行中和已完成</font>的生产批次；
    2. 按钮展示规则
        1. 生产审核进度列表展示“查看详情”按钮；
    3. 排序规则
        1. 生产审核进度列表默认以生产开始时间降序排序；
    4. 字段说明

| **列表字段项** | **字段说明** | **固定（Y/N）** | **字段备注** |
| --- | --- | --- | --- |
| 产品名称 | 产品的名称 | Y |  |
| 产品编码 | 产品的编码（合并编码） | Y |  |
| 产品规格 | 产品的规格 | Y | |
| 生产批号 | 计划的生产批号 | Y | |
| 工艺名称 | 该生产批次的工艺名称 | Y | |
| 生产开始时间 | 该生产批次的生产开始时间（生产前确认的时间） | Y | |
| 审核状态 | 1. 该生产批次的审核状态：审核中或审核完成；<br/>2. 审核中：当前生产批次下有处于待提交、已提交或审核中的工序/工艺审核节点时，审核状态展示为“审核中”；<br/>3. 审核完成：当前生产批次下所有工序/工艺审核节点都已完成时，展示“审核完成”； | Y | |
| 操作 | 展示操作按钮 | Y | |


    5. 筛选规则

| **字段项** | **说明** |
| --- | --- |
| 产品信息 | 左侧树，模糊查询，对产品树的产品分类和产品信息进行筛选 |
| 生产批号 | 模糊查询 |
| 工艺名称 | 模糊查询 |


5. 功能
    1. 查看详情
        1. 选择生产批次点击【查看详情】按钮，进入审核详情页面，展示生产信息和该生产批次的所有工序审核和工艺审核节点的审核状态；
