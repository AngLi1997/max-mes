![](https://cdn.nlark.com/yuque/0/2023/png/32680400/1702894024049-a1bf65e5-30ca-4895-9699-b4d1cb8b1a22.png)d.页面说明  
   批签发文件管理模块页面分为2大区域，分别为筛选区、签名日志列表；  
   页面初始化时，展示当天向前最近30天全量数据；若无数据，列表中展示缺省页；  
   权限说明：菜单权限，拥有菜单权限人员可进入批签发文件管理菜单；

   1.筛选区  
    “选择系统”：点击“选择系统”下拉选择框，选中选项后，点击“查询”按钮，在日志列表区展示符合搜索条件数据；  
    “签名人”：手动输入签名人，点击“查询”按钮，在日志列表区展示符合搜索条件数据，支持模糊搜索；  
      时间选择：选择开始时间、结束时间，点击“查询”按钮，在日志列表区展示符合搜索条件数据；  
                       时间选择最长选择时间为30天（选中开始时间向前或向后最长选择不超过30天）；

      支持联合搜索；

      点击“重置”按钮，清空所有搜索条件，列表信息实时获取全量数据（近30天）；

   2.签名日志列表  
      i.字段说明

| 字段项 | 类型 | 是否固定列 | 是否必填 | 来源 | 说明 |
| :---: | :---: | :---: | :---: | :---: | --- |
| 系统名称 | varchar | 是 | 是 | 登录MES后选择系统名称 | / |
| 签名类型 | varchar | 是 | 是 | 密码认证 | 当前仅有密码认证 |
| 签名动作 | varchar | 是 | 是 | 生产执行App、批签发审核 | 操作、复核签名组件；按钮触发后账号密码输入 |
| 签名人 | varchar | 是 | 是 | 生产执行App、批签发审核 | 输入账号密码对应用户，目标字段：用户名称 |
| 签名对象 | varchar | 是 | 是 | 生产执行App、批签发审核 | 详见b.日志触发点 |
| 签名时间 | date | 是 | 是 | 生产执行App、批签发审核 | 签名确定时间：yyyy-mm-dd HH:mm:ss |
| 状态 | varchar | 是 | 是 | 生产执行App、批签发审核 | 成功、失败；判断账号名密码是否一致；一致记录成功；不一致记录失败，签名弹窗点击“确定”按钮触发 |
| 备注 | varchar | 是 | 是 | 生产执行App、批签发审核 | 业务端传入展示，若为空则展示空 |


      “签名对象”“备注”默认展示20个字段，超出部分以“...”代替，移入单元格后hover展示数据；  
        排序规则：签名时间倒序排序；

      ii.交互说明  
        点击“导出”按钮，以列表形式导出pdf文件，导出字段“签名动作”、“签名人”、“签名对象”、“签名时间”、“状态”；导出字段数据为字段全量数据；  
        点击“查看详情”按钮，以弹窗形式展示选定行数据全量数据；
