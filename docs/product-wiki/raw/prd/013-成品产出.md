参考配料称量的配置：[https://bmos.yuque.com/bp7n97/tx8g07/pbo2eizhh4xw6z3k#S7GPT](https://bmos.yuque.com/bp7n97/tx8g07/pbo2eizhh4xw6z3k#S7GPT)

    1. 业务组件中分组仅展示在记录项中配置的业务字段基础组件；
2. 组件功能配置
    1. 选择成品产出组件，功能配置展示<font style="color:#DF2A3F;">工位信息</font><font style="color:#000000;">，可以选择工位；</font>
    2. <font style="color:#000000;">工位信息多选，来源为当前工序绑定的房间下的工位；组件配置工位控制该成品产出组件哪些人能操作；</font>

#### 成品产出组件执行 <font style="background:#F8CED3;color:#70000D">p0</font>
##### 成品产出
<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2024/png/38732851/1714122316775-f2d07107-2175-4b45-abdc-5fc5b9f152ff.png)

1. 批记录执行页面，点击记录中“成品产出”组件下任意字段基础组件，进入成品产出功能页面，回显成品批次信息；

| **字段项** | **字段说明** | **必填** | **校验** | **字段备注** |
| --- | --- | --- | --- | --- |
| 成品名称 | 成品名称，回显生产工艺的产品信息（成品），不可修改 | Y |  |  |
| 成品编码 | 成品合并编码，回显生产工艺的产品信息（成品），不可修改 | Y |  |  |
| 成品规格 | 成品规格，回显生产工艺的产品信息（成品），不可修改 | Y |  |  |
| 成品批号 | 默认回显为生产批号，不可修改 | Y |  |  |
| 单件量 | 成品产出的单件量 | Y |  |  |
| 单位 | 单件量对应的单位 | Y |  |  |
| 产出件数 | 该单件量对应的产出件数 | Y |  |  |


    1. 若成品产出组件配置了工位信息，工位绑定的用户才能进入成品产出组件作业，非工位绑定的用户点击该成品产出组件，提示缺少工位操作权限；
    2. 若当前生产批次的工艺绑定产品不是成品，点击成品产出组件提示非成品工艺缺少批次信息；
    3. 成品产出页面点击【添加产出信息】，新增一行产出信息（单件量、单位和产出件数）；
    4. 签名

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2024/png/38732851/1714123689971-85a8b585-6789-4579-91d4-d0f817fdc7ae.png)

        1. 成品产出页面点击【确定】按钮，弹出操作人账号密码校验弹窗，“操作人”默认为当前移动端登录账号；
        2. 账号密码校验通过后列表中成品产出信息批量创建；当密码错误时，提示操作人密码错误；
    5. 点击【取消】按钮退出成品产出组件；
    6. 日志
        1. 操作日志：记录1条操作日志：操作类型：新增；业务操作：成品产出；
        2. 签名日志：记录1条签名日志，签名动作：成品产出；
