# 记录与数据集主数据

> 电子记录（eBR）与数据集是 MES 批记录填报体系的两层载体：
> - **电子记录**：生产执行时人/设备填报的载体，由 Word(.docx) 导入并解析为 HTML，承载基础组件 + 业务组件 + 公式配置；归属 120-020-001 记录配置。
> - **数据集**：批签发自动取数的中介层，绑定工艺 → 拉取记录项模板 → 数据点与组件 1:1 绑定（或二次处理）；归属 120-040-001 数据集管理。
>
> 边界：记录是"填报模板"，数据集是"取数映射"。工艺=骨架，记录=填什么，数据集=取什么。

## 电子记录

### 创建链路

Word(.docx ≤10MB) 上传 → 按**大纲级别 1 级**段落拆分为多个"记录项" → 转 HTML（字号 pt→px、字体、表格、图片、公式保留） → 记录项根 = 记录名称，叶子 = 记录项名称 → 首个 1 级大纲之前的内容丢弃 → 进入记录编辑器配置组件。

> 未上传文件时可创建"空记录"（无记录项）；上传但无 1 级大纲 → 解析失败提示"记录缺少一级大纲"。文件解析能力由平台提供，可复用。

### 基础组件（11 类）

| 组件 | 用途 |
|---|---|
| 文字 / 数字 | 文本/数值录入（数字组件可挂公式、范围限制、数值相等） |
| 单选 / 多选 | 选项内容配置，单选默认 1 项不能删，最多 30 项 |
| 选择 | 数据来源=选项内容 或 数据字典 |
| 日期 / 时间 | 日期样式 + 日期格式 + 录入方式（当前时间/手动选择）；时间组件含时间修约 |
| 附件 | 文件附件 |
| 提交签名 / 复核签名 | 电子签名（[[esignature]]） |
| 手写签名 / 拍照 | 扩展组件 |

组件编号以记录项维度自增且不重复；删除再新增不回收编号。

### 业务组件（按工艺执行环节）

配方信息 / 生产信息 / 配料称量 / 配料投入 / 生产投料 / 中间品产出 / 成品产出 / 配液量取 / 配液投入 / 配液产出 / 设备数采绘图 / 检验结果

> 其中**生产信息**为展示型组件（回显产品名称/编码/规格、工艺名称、生产批号/批量/单位、修订数量，数据来源为生产批次的产品信息/工艺配置/生产计划），其余为作业型组件（在工艺中配置物料/工位绑定后执行）。

业务组件下挂"分组属性"，分组下挂基础组件字段（如生产投料 = 物料详情分组 + 物料汇总分组）。业务组件本身**不能配公式**，只能作为公式参数。业务组件在记录项中配置字段定义，在工艺中配置物料/工位绑定（见 [[feature-process-and-execution-model]]）。

### 公式配置

基础组件可挂公式，公式来源为 [[domain-production-config]] 公式管理中"确认"态的公式：

- **计算公式**：数字组件挂计算公式 + 表达式 + 公式修约 + 精度 + 参数（数字组件/选择组件）。
- **关联引用公式**：文字/数字/日期 组件挂引用，支持格式配置（数值：修约数/百分比/科学计数法；日期：日期样式）。
- **求和/最大值/最小值/平均值**：数字组件聚合多参数（≤100），可配置取值方式（最新有效/所有有效）。
- **字符串拼接公式**：文字组件按字符配置拼接参数。
- **时间差/日期计算公式**：日期/时间组件专用，含计算方式（增加/减少时长）。

公式修约方式同 [[recipe-bom-master]]：四舍五入 / 四舍六入五成双（默认）/ 向上 / 向下；未配置时默认四舍六入五成双、最大精度 15 位、不补零。

### 记录版本机制

```
新增记录 → 编辑（默认） → 审批 → 确认 → 作废
                 ↑________________|  （仅"确认/作废"状态可新增版本）
```

- 记录 = 部门授权（首次保存强制）+ 绑定产品（多对多）；记录版本继承数据权限。
- 新增版本两种方式：**复制已有版本**（默认）/ **重新上传记录**。
- 同时只允许一个"编辑"或"审批"状态版本；存在编辑/审批态时无法新增版本。
- **记录 ↔ 公式的双向绑定**：确认态公式可批量绑定记录（公式侧【绑定记录】），记录侧也可批量绑定确认态公式（记录列表【绑定公式】）。必须先绑定才能在记录编辑器-公式配置中选用。

## 数据集

### 实体定位

数据集 = "工艺 → 记录项 → 组件" 与 "批签发模板单元格" 之间的取数中介。

```
产品（platform）
  └─ 数据集（多数据源标识：是/否）
       └─ 数据集版本（编辑中 → 已确认）
            ├─ 数据点树（自定义分组 + 数据点，名称版本内唯一）
            └─ 关联工艺版本 → 拉取工艺归档顺序的记录项模板
                 └─ 数据点 ↔ 记录项组件（1:1 组件关联 / 1:N 组件处理）
```

数据集类型：**批记录模板配置**（默认，已实现）/ 三方接口配置 / 数据库表配置（后两者暂未实现）。

### 数据点 ↔ 组件绑定

- **组件关联**（1:1，默认）：双击组件完成绑定，组件橙色高亮；已完成绑定的数据点在树中标蓝。数据点-组件严格 1:1，不存在一多关系。
- **组件处理**（1:N，二次处理）：一个数据点引用多个组件数据，按公式做二次处理（数值修约/格式转换/拼接/解析）。
- **多数据源标识**：标识为"是"的数据集可关联获取多个生产批次的数据，按批签发模板规则自动写入对应单元格（[[domain-lot-release]]）。

### 数据点二次处理公式（内置高代码，独立于公式管理）

- 数值修约：四舍五入、四舍六入五成双、小数位数修约（ROUND）
- 数学：SUM / AVG / MIN / MAX / CONCAT
- 日期：日期解析、日期区间拼接（跨天补齐为 yyyy-mm-dd 00:00:00）
- 阈值判断：NUMCONFIRM(参数, 判断值小, 判断值大)，不在范围内标红提示

校验：日期公式仅支持日期组件；min/max 仅支持数字组件；单参数仅绑一个组件；连接符限 `-`/`~`/`_`。

### 数据集版本机制

```
新增数据集 → 编辑中（默认） → 已确认
                                ↓ 升级版本（备注必填）
                             编辑中（版本号 +1）
```

- 数据集名称在产品下唯一；版本号顺序递增（1, 2, 3 ...）。
- 升级版本回显被升级数据；数据集名称/类型/关联产品/关联工艺不可改。
- 同一数据集同一时刻仅允许一个"编辑中"状态版本，可存在多个"已确认"。
- **无启用/作废概念**（不同于记录）：数据集通过"最新确认版本"字段标识生效版本。

## 与工艺/批签发的关系

- **记录 ↔ 工艺**：工艺版本绑定 1..N 个记录版本（级联选择，已作废版本不可选）；记录项被工艺步骤/任务节点引用做组件业务配置。
- **数据集 ↔ 工艺**：数据集版本关联 1 个工艺版本；记录项下拉来自工艺"归档顺序"中绑定的工序步骤。
- **数据集 ↔ 批签发**：批签发模板通过数据集拉取生产数据自动填入。

详见 [[feature-process-and-execution-model]]、[[domain-lot-release]]。
