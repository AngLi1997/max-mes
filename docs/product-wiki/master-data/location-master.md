# 货位主数据

> 货位是物料/货品的物理位置载体，分两条线：**WMS 仓库货位** 与 **MES 车间暂存货位**。
>
> 本页只展开两类货位的实体字段与边界；入库/出库/移库等业务操作见 [[domain-warehouse-interaction]]。

## 双线货位（关键设计）

```
WMS 仓库货位（仓库内）               MES 暂存货位（车间内 / 线边库 / 中间站）
   存储区域树（自定义）                  存储区域树（自定义）
   └ 货位 ─ 绑定 货品件                └ 暂存货位 ─ 绑定 物料件
                                        ↑
                            领料接收时货品件 → 物料件 转换
```

| 维度 | WMS 货位 | MES 暂存货位 |
|---|---|---|
| 归属系统 | WMS 网页端（150） | MES 网页端（120）+ MES APP（121） |
| 配置菜单 | 002-货位配置（仓库配置下） | 010-暂存间配置（生产配置下） |
| 管理菜单 | 001-库存管理（WMS 网页端，货品件/货位库存管理） | 008-暂存间管理（生产管理下）+ 004-库存管理（MES 移动端） |
| 绑定对象 | 货品件 | 物料件 |
| 业务定位 | 仓库内存储 / 仓库发料 | 车间暂存 / 领料接收 / 物料预定 |
| 数据权限 | 部门授权 | 部门授权（同模型） |

## WMS 货位（002-货位配置）

### 实体字段

| 字段 | 说明 |
|---|---|
| 所属区域 | 自定义分类树（存储区域）；多级以 `/` 分隔 |
| 货位名称 | 手动输入 |
| 货位编码 | 手动输入，全校验唯一 |
| 部门授权 | 必填，可多部门；首次创建必须授权 |
| 备注 | 可选 |

### 状态与约束

- 启停：默认停用；启用后若货位中存在物料件/货品件，**无法停用**。
- 删除：必须停用状态，且**已产生货位日志的货位无法删除**。
- 排序：以分类节点创建时间升序、货位编码升序。

## MES 暂存货位（010-暂存间配置）

实体字段、启停、删除约束与 WMS 货位**完全一致**（仅业务术语不同：货位 → 暂存货位）。差异点：

- 部门授权控制**车间可见性**：暂存间管理员只能操作授权范围内的物料件。
- 删除校验项为「已产生货位日志」时阻塞（货位日志是 MES 暂存间产生的日志类型，见 [[flow-compliance-traceability]]）。

## 物料件 vs 货品件（跨系统衔接）

**核心衔接动作：MES 领料接收**（[[flow-material-flow]] 第 5 步）

- 触发：MES 批记录"领料接收"组件，选择已发料的领料单。
- 转换：勾选货品批次/货品件 → 扫描或选择暂存货位 → 双签名（接收人+递交人）→ 生成 MES 物料件。
- **字段继承**（货品批次 → 物料批次）：
  - 批号、有效日期、生产日期、水分%、含量%、原厂批号、供应商、生产商 等全部继承；
  - **原货品合并编码 → MES 物料批次 `原始编码` 字段**；
  - 若原货品批次为成员货品，MES 以**父级物料**作为物料批次的物料信息；
  - **原货品件号 → MES 物料件 `物料来源` 字段**（用于追溯流转过程）；
  - MES 物料件号按 MES 规则重新生成（不继承货品件号）。
- 接收后批量打印物料件标签（标签字段：物料、物料批号、物料件号、物料量、有效日期、暂存货位 等）。

## 暂存间操作（008-暂存间管理）

暂存货位上的物料件操作（每项均涉及物料日志、货位日志、操作日志、签名日志）：

| 操作 | 触发签名 | 量值影响 |
|---|---|---|
| 物料接收（创建物料件） | 接收人 + 递交人 | 创建物料批次/物料件，初始量=可用量 |
| 物料入库（已存在物料件入暂存） | 接收人 + 递交人 | 物料件与暂存货位绑定 |
| 物料出库（出暂存货位） | 出库人 + 领用人 | 物料件与暂存货位解绑 |
| 物料移库（暂存间之间） | 移库人 | 物料件量不变，仅切货位 |
| 物料退库（退回仓库） | 退库人 + 复核人 | **物料件消耗**，与暂存货位解绑 |
| 物料销毁 | 销毁人 + 复核人 | **物料件消耗** |
| 物料使用 | 使用人 + 复核人 | **物料件消耗** |
| 物料盘点 | 盘点人 + 复核人 | 调整初始量/消耗量，可用量重算 |
| 物料预定（绑生产批次） | 操作人 + 复核人 | 可用量不变，预定量↑ |
| 取消预定 | 操作人 + 复核人 | 预定量↓，可用量↑ |
| 拆包出库 | 出库人 + 领用人 | 原件留货位，拆出新物料件出暂存（继承预定信息） |
| 标签打印 | — | 仅打印 |
