# 物料主数据

> 物料是 bmos 全产品族流转的语义核心。本页是 product-wiki 的 ★枢纽页，被 [[flow-material-flow]]、[[domain-warehouse-interaction]]、[[domain-production-management]] 等引用。
>
> 实体边界与主数据收口决策一致：**platform 是单一真相源**（[[product-overview]]），MES/WMS 不自建物料。

## 主数据边界

```
platform 物料平台（单一真相源）
   │  物料分类树 + 物料信息 + 单位
   │
   ├──下发(platform → 业务, 多选)──► MES：产品/原辅包/中间品（落地为停用态记录）
   │                              WMS：货品（落地为停用态记录）
   │
   └──同步(业务 ← platform)─────►  业务侧【同步】按钮拉取「启用且未同步」的物料
```

- **下发**：从平台推到业务（多选业务系统），落地为**停用态**；下发时父级分类与关联所属物料一并下发。
- **同步**：业务侧主动拉取启用状态物料；同步成功后业务物料默认**停用态**，由业务侧启停控制可用性。
- **业务侧新增物料**：先去平台注册（平台默认置为启用并标注已下发业务），再回业务侧创建；不允许直接在业务侧创建。
- **业务侧编辑约束**：若该物料已下发至多个业务场景，**不允许修改**平台基础信息。

## 分类层级与编码规则

- 物料分类为自定义树；分类**带物料编码**时，展示为「**合并编码**-物料名称」。
- **合并编码 = 各级分类编码顺序拼接 + 物料编码**，全平台唯一。
  - 例：父分类 `F` + 子分类 `01` + 物料 `001` → 合并编码 `F01001`。
- 新增/编辑时**校验合并编码全局唯一**：跨层级组合重复则失败（如已有 `c/p/x`，再建 `cp/x` 校验不通过）。
- 删除分类：分类下有子分类、物料信息或已下发业务时不允许删除。
- 排序：以分类编码顺序排序。

## 业务物料类型与关键字段

物料下发到业务后形成「业务物料」，承担该业务特有的执行属性：

| 业务物料 | 归属菜单 | 业务特有字段 | 用途 |
|---|---|---|---|
| 产品 (产品信息) | MES 120-010-003 | 内包规格/包装规格/生产周期(天)/产品标识/成品标识/批记录绑定 | 配方/工艺/批签发/成品产出 |
| 原辅包 (原辅包信息) | MES 120-010-001 | 预置皮重/临期提醒/供应商/生产商/级别/剂型 | 配方物料/工艺业务组件/投料 |
| 中间品 (中间品信息) | MES 120-010-002 | 默认效期/生产商/**物料信息·批次·件 自定义字段** | 中间品产出/配液产出 |
| 货品 (货品信息) | WMS | **单件量**/供应商/生产商 | 货品入库/仓库发料 |

- 三类业务物料均支持**成员物料/所属物料**关系：父级物料用于配方与计划；成员物料用于实际领料与追溯；领料接收时成员批次继承到父级物料批次（见 [[flow-material-flow]]）。
- 中间品支持自定义字段（物料信息/物料批次/物料件 三类），用于扩展业务属性。

## 单位模型

| 类型 | 关键字段 | 说明 |
|---|---|---|
| 标准单位 | 精度 / 修约方式 | 修约方式：四舍六入五成双(默认) / 四舍五入 / 向上/向下舍入 |
| 扩展单位 | 换算表达式 / 精度 | 与标准单位换算；换算方式分「数值」与「参数」（参数对应 LIMS 检验结果）|

- **一物料绑一标准单位 + 多扩展单位**（多选）；切换标准单位时扩展单位重置为该标准下全部。
- 业务侧单位下拉范围 = 物料绑定的标准单位 + 扩展单位。
- 精度校验：以 `kg`(精度3) 为标准，`t`(换算 1t=1000kg) 应配 6 位精度，避免换算精度丢失。

## 量值模型（核心）

物料在系统中以**双层批次-件**结构管理量值：

```
物料(平台) ──┐
             │
业务物料 ────┤  1 : N  物料批次  ── 1 : N  物料件（MES）/ 货品件（WMS）
             │
             └── 各层级均维护：初始量 / 可用量 / 预定量 / 消耗量
```

**恒等式（任意层级）**：`初始量 = 可用量 + 预定量 + 消耗量`

- **物料批次**：业务批次级量值汇总（考虑单位换算）；货品批次(WMS)字段含 批号/原厂批号/生产日期/有效日期/水分%/含量%/报告单编号/放行单编号/供应商/生产商。
- **物料件 / 货品件**：物理最小管理单元，件号全局唯一（正整数递增，最大 10 位，超限回 1）。
- **质量状态**（物料批次）：`待验 / 合格 / 不合格 / 已取样 / 限制性放行` —— GMP 五态。

### 量值流转三类动作

| 动作 | 可用量 | 预定量 | 消耗量 | 触发场景 |
|---|---|---|---|---|
| **预定** | ↓ | ↑ | 不变 | 领料计划完成 → 货品批次预定 |
| **发料/消耗** | ↓（超出预定时） | ↓ | ↑ | 仓库发料/投料/称量/使用/销毁 |
| **取消预定** | ↑ | ↓ | 不变 | 取消领料计划/取消物料件预定 |

- **物料件 vs 货品件 跨系统转换**：MES 领料接收时货品件 → 物料件，**继承批次信息**（批号/有效期/水分/含量/供应商等），原货品合并编码记入「原始编码」字段，原货品件号记入「物料来源」字段，用于全链路追溯（见 [[flow-material-flow]]）。

## 启停与同步机制

- 业务物料启停独立于平台物料；删除仅在业务侧删除，平台与其他业务不受影响。
- **平台物料停用前置**：未下发任何业务、未作为所属物料被成员物料关联。
- **业务物料停用前置**：未在配方中配置、未作为所属物料被成员关联。
- **业务物料删除前置**：未产生物料批次/货品批次。
