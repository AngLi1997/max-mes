# 配方与生产 BOM 主数据

> 配方（Product Recipe）与生产 BOM 在 BMOS-MES 中**共用同一组配置对象**：配方偏"物料清单 + 量值模型"，BOM 偏"称量需求"。两者都挂在产品信息树下，由部门授权控制可见性，由工艺版本引用生效。
>
> 主数据边界：**产品信息**来自 platform（[[material-master]]），配方/BOM 是 MES 自有主数据；物料平台下发后落地为停用态，需启用才能进配方。

## 实体关系

```
产品（platform 下发）
  └─ 配方（MES 自有，挂产品）
       └─ 配方版本（编辑/审批/确认/启用，启用态全局唯一）
            ├─ 配方物料行（N 行）
            │    ├─ 数量类型 + 数量 + 单位
            │    ├─ 物料精度 + 修约方式
            │    ├─ 折干折纯（无/折纯/折干折纯/折干折纯带参数）
            │    └─ 允差（拆包/配料/余料/配液/余液 各一组上下限）
            └─ 称量需求行（按物料展开 N 行）
                 ├─ 需求目标量 + 单位（带出配方物料单位，不可改）
                 └─ 需求用途（文本）
```

## 配方物料量值模型

| 维度 | 取值 | 说明 |
|---|---|---|
| 数量类型 | 标准量 / 固定量 / 适量 | 标准量随生产批量按比例换算；固定量不随批量调整；适量时物料量由生产时决定（无理论量） |
| 数量 + 单位 | 正数，整数 ≤10 位、小数 ≤9 位 | 单位来自所选物料在平台绑定的标准单位与扩展单位 |
| 物料精度 | 正数，整数 ≤10 位、小数 ≤9 位 | 例 "0.020"，修约后需补零至该精度（GB/T 8170-2008） |
| 修约方式 | 四舍六入五成双（默认）/ 四舍五入 / 向上舍入 / 向下舍入 | 与 [[record-dataset-master]] 公式修约一致 |
| 折干折纯 | 无 / 折纯 / 折干折纯 / 折干折纯带参数 | 折干=扣水分，折纯=扣含量（无水计，>100% 按 100%）；带参数 = 折干折纯后除以参数；切换方式时参数清空 |

### 五类允差（拆包/配料/余料/配液/余液）

每类允差一组"上下限 + 方式"，方式可选：
- **百分比**：按目标量的百分比计算，配液场景常用；上下限 [0,100]，小数 ≤3 位。
- **固定值**：按目标量的固定值允差，单位沿用配方物料单位，可按称量单位换算；拆包场景常用；正数，整数 ≤10 位、小数 ≤9 位。

未填默认上下限为 0；可只填一侧。允差闭区间（可等于）。

| 允差 | 用途 |
|---|---|
| 拆包允差 | 拆包称量业务组件 |
| 配料允差 | 配料称量组件、称量中心、称量工单执行 |
| 余料允差 | 余料称量 |
| 配液允差 | 配液量取组件 |
| 余液允差 | 余液量取组件 |

### 称量需求（BOM 侧）

每条配方物料可挂多条"称量需求"：**需求目标量**（正数，整数 ≤10 位、小数 ≤9 位）+ **单位**（带出物料单位，不可改）+ **需求用途**（文本，非必填）。保存时自动排除未录入目标量的空行。称量需求是 BOM 偏称量侧的体现，供配料称量、称量工单等下游消费（见 [[flow-weighing-execution]]）。

## 版本机制

```
新增配方 → 编辑（默认）
   ↓ 发起审批（必须存在编辑态版本 + 用户有"发起审批"权限 + 已配置配方审批流程）
   审批 ← 退回回编辑 / 不通过回编辑
   ↓ 审批通过
   确认
   ↓ 启用（若已有启用版本则启用失败）
   启用（同一配方全局唯一）
   ↓ 停用
   停用（可再次启用）
```

- 新增/首次保存触发**部门授权弹窗**（必须选部门）；新增版本/编辑版本不重复触发。
- "新增版本"复制原版本全部配方物料与称量需求；**配方名称+产品不可改**，版本号唯一校验。
- 启用态全局唯一：若已有启用版本，再次启用失败并提示。
- 升版约束：可同时存在多个非"确认"状态的版本；不校验"编辑/审批"状态版本唯一性。
- 数据权限：版本继承配方数据权限；只能选择本部门下的配方。

## 与工艺的关系

工艺版本新增/编辑时选择**启用状态的配方版本**作为绑定（来源限定为工艺产品对应的、当前用户有数据权限的配方）。一条工艺版本 ↔ 一条配方版本（1:1）。配方物料行通过工艺工序节点的"配方物料"字段在工序/步骤/任务节点中二次分配，作为配料称量、生产投料、中间品产出等业务组件的物料来源。

详见 [[feature-process-and-execution-model]]。
