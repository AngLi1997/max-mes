# 称量执行端到端流程

> 本页描述从「需求产生」到「物料件生效并被物料投入组件消耗」的称量执行端到端时序。
> 实体模型与状态机见 [[feature-weigh-center]]；域功能清单见 [[domain-weighing]]。

## 流程概述

- **触发**：生产批次配料确认（二代）或指令单下发（一代）时由物料投入组件配置自动创建称量需求。
- **输入**：称量需求（含物料批次、需求量、单位、称量中心、需求日期、需求用途）。
- **输出**：已签名的生效物料件，预定到生产批次，可被 [[feature-process-and-execution-model]] 的物料投入组件扫码消耗。
- **执行端**：121 移动端工位（工位绑定用户/秤具/标签打印机）。

## 序贯步骤

### 1. 称量需求自动创建

- **触发点（二代）**：生产批次配料确认时，按生产 BOM 配料配置创建称量需求，需求状态默认 **未规划**。
- **触发点（一代）**：指令单下发时，按物料投入组件配置（物料来源=称量中心）创建称量需求。
- 需求量 = 配方物料需求量 ×（生产批量/配方批量），按配方物料精度修约；固定量/适量不放大。
- 同时生成：需求日期（计划生产日 + N 日）、需求失效时间（N 日）。
- 物料投入组件配置见 [[feature-process-and-execution-model]]。

### 2. 称量需求状态流转

```
未规划 ──规划到工单──► 未称量 ──首次添加物料件──► 称量中 ──满足目标范围──► 已完成
                                                                超时/批次结束 ──► 已失效
```

- 工单取消时，未称量需求回退到未规划；删除工单中需求也回退到未规划。
- 详见 [[feature-weigh-center]]。

### 3. 称量工单规划（120 网页端）

- **聚合维度**：物料批次（区分原辅包/中间品）+ 物料需求量单位 + 称量中心 + 计划生产日期。
- **工单编号**：`yyyyMMdd + 流水号`（如 `20240613001`），流水号正整数递增，超出最大位数继续增加，系统全局唯一。
- **工单状态**：`编辑中 → 已下发 → 已完成`。
- 规则：
  - 工单计划执行时间默认为工单中最早的称量需求计划生产时间。
  - 自动规划按聚合维度批量生成；手动规划由用户勾选未规划需求。
  - 工单下必须保留至少 1 条需求，无法全部删除。
- 取消：仅编辑中状态可取消；工单下若有需求处于称量中/已完成，不可取消。

### 4. 移动端工单执行（121 移动端，七段子流程）

**4.1 选择称量工单/物料需求**
- 工位绑定用户看到该称量中心下未执行完成的工单。
- 工单所有需求都已失效时不展示，需进称量历史查看。
- 默认选择首个未称量需求；称量中需求存在时不可切换。

**4.2 确认物料批次/投入物料件**
- 扫码/手输物料件号/容器编号；按校验顺序：物料批次匹配 → 物料件有效 → 有效期 → 质量状态（合格/限制性放行）→ 未预定其他批次 → 已出暂存。
- 校验通过后物料件消耗（可用量↓、消耗量↑，预定量不变）。
- 物料批次首次添加物料件时，需求状态 **未称量 → 称量中**。

**4.3 签名确认称量人员（首次）**
- 称量人固定为当前登录用户；复核人为称量中心工位下且具备权限码角色的人员（[[data-permission]]）。
- 双签名（账号密码校验，[[esignature]]）通过后方可进入「模式&设备」页面。
- 签名日志 2 条：`称量工单执行-称量`、`称量工单执行-复核`。

**4.4 选模式 & 秤具**
- **增重称量**：默认选项，展示称量中心工位下「秤具标签」设备。
- **手动称量**：无秤具，手输皮重/毛重，净重自动计算。
- 秤具占用：长链接建立后占用；当前批次称量完成或长链接超时自动释放。
- 校验顺序：校准状态（当日有效）→ 可用状态 → 单位一致 → 已被占用。

**4.5 清零 → 去皮 → 称量打码 → 创建物料件**
- 清零：发清零指令，失败提示秤具连接异常。
- 去皮：发去皮指令，记录皮重。
- 称量打码：秤具连续 3 次稳定一致读数方为有效；净重 > 0；不大于「批次剩余量+允差上限」。
- 称量成功后**创建新物料件**（默认未签名，初始量=预定量=称量结果，可用量=消耗量=0），并打印标签。
- 物料件可绑定容器（1:1）、入暂存货位。
- 五类日志同步：物料日志 ×2（称量/复核）、货位日志 ×2（入库-称量/复核）、称量日志 ×1、操作日志 ×1、签名日志已记。

**4.6 结果确认与继续/换需求**
- 净重 < 下限 → 「继续称量」按钮，回清零&去皮页面。
- 净重在范围内 → 「更换物料需求」按钮，回物料信息页。
- 净重 > 上限 → 报错，需走超范围签名（权限码）方可完成。
- 「直接完成称量」需单签名（权限码），签名动作为「完成物料称量」。

**4.7 称量结果页 → 物料件签名生效**
- 称量结果页点【签名】，称量人+复核人双签名通过后，未签名物料件**批量**转为已签名。
- 物料件签名生效才改变物料批次量值：初始量↑、可用量↑（余料物料件）、预定量↑（称量物料件）。
- 已签名物料件可补打标签；未签名物料件存在时不可更换称量人员、不可退出组件。

### 5. 余料称量（强制）

- 工单/任务下**最后一个**称量需求完成后，强制进入余料称量。
- 余料目标量 = 物料批次物料总量 − 该批次物料称量已称量值。
- 余料物料件**不预定**生产批次，初始量=可用量（预定量=0）。
- 余料允差独立于配料允差，来自配方物料余料允差配置。
- 全部余料物料件签名生效后，工单状态 **已下发 → 已完成**。

### 6. 工单完成

- 完成条件：所有需求已完成 + 所有物料件已签名 + 余料称量完成。
- 工单完成后可在称量历史（121-020）查询；称量日志（120-050-005）统一展示配料/余料/产出/拆包等类型。

### 7. 物料件被物料投入组件消耗

- 已签名且预定到当前生产批次的物料件进入 [[feature-process-and-execution-model]] 的物料投入组件。
- 物料投入组件按 5 状态管理物料件：`待投料 → 投料中 → 已投料`，失效/未签名为异常态。
- 扫码确认设备 → 投料人签名 → 物料件状态投料中→已投料；物料件预定量↓、消耗量↑。
- 投料完成后回填批记录「投料详情」与「物料汇总」分组字段。

### 8. 物料件消耗的其他入口

除「物料投入组件」外，已签名物料件还可通过以下组件消耗（共享 5 状态机与投料人单签名、量值变化规则）：

| 入口 | 物料件来源 | 上游计划 | 关键差异 |
|---|---|---|---|
| 配料投入组件（009） | 配料称量产生的物料件 | 配料计划/配料单 | 投料前须先确认配料单；物料件默认展示待投料，余料不展示；切换配料单受限于是否已有「已投料」物料件 |
| 配液投入组件（021） | 配液量取产生的物料件 | 配液计划/配液单 | 与配料投入同构；物料件来源是「配液量取」而非「配料称量」，绑定配液单；工位可选范围包含工艺产线下的工位（配料投入仅限工序房间下工位） |

> 配液链路（019→020→021→022）的量取与产出环节**沿用统一物料件模型与签名机制**（[[feature-weigh-center]] 配液子链路小节）；物料件的消耗既可经物料投入组件，也可经配料投入/配液投入组件，三者互斥但状态机一致。

## 关键分支与异常

| 分支 | 触发条件 | 处理 |
|---|---|---|
| 余料超范围 | 净重 > 余料上限 | 超范围签名（权限码）通过后认为该批次余料完成 |
| 更换物料批次 | 物料批次无法继续称量 | 单签名（权限码）后回物料信息页重新添加 |
| 更换称量人员 | 人员变更 | 原称量人+原复核人双签名 → 新称量人+新复核人双签名；未签名物料件存在时不允许更换 |
| 工单取消 | 仅编辑中状态 | 工单下称量中/已完成需求存在时不展示取消按钮 |
| 秤具长链接超时 | 异常占用 | 自动释放占用状态 |
| 称量需求失效 | 超时/批次结束 | 未规划/未称量状态的需求转为已失效 |
| 物料件未签名限制 | 工序/批次完成时校验 | 存在未签名物料件则不允许完成（生产执行步骤强制，工序/批次级别暂未启用） |
