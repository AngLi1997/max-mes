# 批生产全流程

> 本页描述一条生产指令单从创建到归档的端到端时序，串联起 [[domain-production-management]] 域内的全部执行节点。
> 配套模型见 [[feature-process-and-execution-model]]；物料量值流转见 [[flow-material-flow]]；归档后审核见 [[feature-lot-release-mgmt]]。

## 流程概述

- **触发条件**：生产计划下达 / 移动端手动创建指令单
- **输入**：已发布的产品信息 + 已发布工艺版本（含配方、工序流程、记录项）
- **输出**：归档的生产历史记录 + 批记录打印件 + 可签发的成品批次
- **关键约束**：未经审批通过的指令单不得分解；未下发的指令单不可执行；未开始生产的指令单方可作废

## 序贯步骤

### 步骤 1：指令单创建（网页端 120-030-001 / 移动端 121-010-002）

- **动作**：选产品 → 选工艺版本（带出工艺流程图、配方生产批量）→ 触发编号规则生成指令单号 & 生产批号 → 录入计划生产时间、批次类型（生产/实验/验证）
- **批量创建**：基于"首批生产时间 + 间隔时长 + 批次数量"批量生成；支持【后续指令单顺延】按当前批次时间重排后续
- **状态流转**：`∅ → 编辑`
- **校验**：指令单编号全局唯一；同工艺下生产批号唯一；工艺须绑定生效的批号/指令单编号规则
- **实体**：生产指令单（详见 [[domain-production-management]]）

### 步骤 2：提交审批（120-030-002）

- **动作**：编辑态指令单点击【提交审批】→ 进入指令单审批流程
- **审批处理**：审核通过 / 审核退回（首个节点不可退回）/ 审核不通过；密码认证；支持会签、或签、抄送
- **状态流转**：`编辑 → 审批中 →（通过）确认 /（退回）编辑 /（不通过）作废`
- **未配置审批流**：提示"无启用的记录审批流程"
- 详见 [[approval-flow]]

### 步骤 3：指令单分解（120-030-003）

- **动作**：进入指令单分解列表，选待分解指令单 → 工艺流程图中点击工序节点 → 【指令单生成】按工序拆出工序级指令单
- **状态流转**：`待分解 → 待确认`（所有工序节点拆完）
- **可见性**：工序级指令单对拥有工艺数据权限 + 工序负责人角色的用户可见

### 步骤 4：指令单确认（120-030-004）

- **动作**：工序负责人选待确认指令单 → 为每个工序步骤配置执行班组（多选必填）→ 【确认指令单】
- **班组范围**：默认显示步骤配置的执行班组；可调整范围为所有启用班组
- **状态流转**：`待确认 → 待下发`（所有工序级指令单确认完成）
- **下发**：选待下发指令单【下发】→ `待下发 → 已下发`；下发后移动端可见

### 步骤 5：生产前确认（移动端 121-010-002）

- **动作**：进入生产批次，依次确认五项：**关联批次 / 执行班组 / 物料预定 / 房间确认 / 设备确认** → 【确定】启动工作流
- **关联批次**：选已下发/执行中/已完成批次的关联工艺批次
- **物料预定**：从暂存货位选物料件预定到当前批次，校验库存量-占用量
- **房间/设备**：按产线/工位过滤，需在校准有效期内且状态可用
- **状态流转**：`已下发 → 生产中`（工作流开始执行）
- **移动端创建入口**：右下角悬浮【创建】可在移动端直接新建指令单

### 步骤 6：工艺执行

- **执行模型**：工序/步骤/任务节点流转，支持并行网关、选择网关、完成条件逻辑表达式 → 详见 [[feature-process-and-execution-model]]
- **节点状态机**：`未激活 → 已激活 → 进行中 → 已完成 / 已结束`（非正常终止为"已结束"）
- **完成条件**：未满足完成条件时【强制完成】需操作人签名（有权限控制）
- **工序重做**：进行中工序可重做，回到工序起点，已完成步骤转进行中；操作人+复核人双签
- **生产控制**：终止生产 / 暂停生产 / 恢复生产，均需操作人签名

### 步骤 7：记录作业

- **基础组件填报**：文字/数字/单选/多选/选择/日期/时间组件 → 移动端缓存（录入值、时间、人员）→ 【保存】批量签名持久化
- **签名组件**：提交签名 / 复核签名 → 直接保存（不走缓存）；支持【继续签名】追加签名行
- **数据修订**：已保存数据再修改触发"修订"语义（黄色底色），需签名确认（详见 [[audit-trail-and-logs]]）
- **公式自动计算**：数字组件可配置公式，蓝色底色标识；超限度红色、修订过黄色
- **趋势分析**：数字组件可查看近 50 批次生效值的趋势图（含上下限/标准线）
- **记录保存校验**：组件首次保存时若已有值，弹窗"记录数据已存在，是否刷新？"

### 步骤 8：业务组件作业

| 业务组件 | 关键动作 | 物料件效果 |
|---|---|---|
| **生产投料**（011） | 扫码识别物料件/容器 → 校验（有效/有效期/质量状态/未预定他人/已出暂存）→ 扫描投入设备 → 投料人签名 → 物料件消耗、回填物料详情&汇总 | 物料件：预定量↓消耗量↑；解绑容器；记录物料日志/操作日志/签名日志 |
| **物料回收**（011） | 选已投料物料批次 → 录回收量+绑定容器 → 回收人签名 → 创建新物料件默认预定本批次+自动打印标签 | 物料件：初始量=预定量=回收量；物料批次预定量↑ |
| **中间品产出**（012） | 产出人+复核人双签 → 选产出物料/批号 → 选模式（产出称量/手动称量/手动产出/扫码去皮）→ 秤具确认 → 清零去皮 → 称量打码 → 创建中间品批次+物料件（默认未签名生效）+入暂存货位+绑定容器+打印标签 | 中间品批次/物料件创建；4 类日志全记录 |
| **成品产出**（013） | 选工位 → 录单件量+单位+产出件数 → 操作人签名 → 批量创建成品物料件 | 成品批次/物料件创建；记录操作日志+签名日志 |

### 步骤 9：请验与检验（步骤级功能）

- **动作**：步骤中触发请验 → LIMS 接收请验单 → 检验结果回传 → 更新物料批次质量状态（待验/合格/不合格/已取样/限制性放行）
- 跨系统协作详见 [[domain-inspection]]

### 步骤 10：工序审核 / 工艺审核

- **工序审核节点**：嵌入工序流程，到达时按节点配置触发
- **工艺审核节点**：工序全部完成后触发
- **审核进度**：在 120-050-009 生产审核进度查看所有节点状态（待提交/已提交/审核中/审核完成）
- 详见 [[approval-flow]]、[[feature-lot-release-mgmt]]

### 步骤 11：归档与查询

- **生产审核进度**：进行中/已完成批次的审核节点详情（120-050-009）
- **生产历史**：已结束批次预览打印、操作历史（120-050-001）
- **批记录打印**：已结束成品批次+关联批次归档拼接预览打印（120-050-002）
- **批签发**：归档后进入批签发流程（[[feature-lot-release-mgmt]]、[[domain-lot-release]]）
- **四大日志**：物料日志/货位日志/称量日志/操作日志，详见 [[flow-compliance-traceability]]

## 状态流转表（指令单维度）

| 状态 | 入口动作 | 可执行操作 | 出口 |
|---|---|---|---|
| 编辑 | 新建/批量创建/审批退回 | 编辑、查看、提交审批、作废、历史 | → 审批中 / 作废 |
| 审批中 | 提交审批 | 查看、审批进度、历史、作废 | → 确认 / 编辑 / 作废 |
| 确认 | 审批通过 | 查看、历史、作废（未开始生产） | → 待分解 / 作废 |
| 待分解 | 进入指令单分解 | 分解、查看 | → 待确认 |
| 待确认 | 全工序拆分完成 | 查看 | → 待下发 |
| 待下发 | 全工序指令单确认 | 查看、下发 | → 已下发 |
| 已下发 | 下发操作 | 查看 | → 生产中（移动端生产前确认） |
| 生产中 | 生产前确认确定 | 工艺执行、暂停/恢复/终止 | → 已完成 / 已终止 |
| 已完成 | 工作流正常结束 | 归档查询 | — |
| 已终止 | 终止生产签名 | 归档查询 | — |
| 作废 | 作废操作（编号追加 `-废yyyyMMddhhmm`） | 查看、历史 | — |

## 移动端执行段

- **入口**：121-010-001 生产管理（生产批次列表）、121-010-002 生产前确认、MES 待办
- **生产批次列表**：按工序执行状态过滤可见批次（数据权限来自步骤绑定班组）
- **MES 待办**：当前待办（工序计划开始时间 ≤ 当天）+ 计划待办（> 当天）；生产前确认聚合置顶
- **生产控制**：终止 / 暂停 / 恢复 / 工序重做 / 强制完成 均需签名
- **记录执行**：基础组件 + 业务组件（投料/产出/配料计划/物料预定 等）

## 关键异常分支

| 异常 | 触发条件 | 处理 |
|---|---|---|
| 指令单作废 | 编辑/确认态、未开始生产 | 编号追加 `-废yyyyMMddhhmm`；确认态作废后移动端不可见 |
| 审批不通过 | 审核节点判定不通过 | 工艺版本回退到"编辑"态；指令单转作废 |
| 强制完成 | 工作流到结束节点但未满足完成条件 | 操作人签名后强制完成该工序，后续正常流转 |
| 工序重做 | 进行中工序需重做 | 操作人+复核人双签；已完成步骤转进行中 |
| 生产终止 | 不可继续生产 | 操作人签名；流程终止；进行中节点转"已结束"；记录归档 |
| 生产暂停/恢复 | 临时停止 | 暂停后展示"恢复生产"按钮；均需签名 |
| 物料件校验失败 | 投料时未出暂存/超有效期/质量状态不符/被他批预定 | 提示具体原因，无法投料 |
