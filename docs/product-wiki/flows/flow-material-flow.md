# 物料流转主链与追溯

> 物料从平台注册到最终成品产出的**全生命周期时序**。本页串联 [[material-master]]、[[location-master]] 实体与 [[domain-warehouse-interaction]] 域功能。
>
> 主链涵盖 9 个序贯步骤，每步都生成对应的物料日志/货品日志/货位日志（[[flow-compliance-traceability]]）。

## 流程概述

- **触发**：生产批次进入批记录执行，触发领料计划组件。
- **输入**：platform 注册的物料 + WMS 货品库存。
- **输出**：成品产出 + 全链路物料追溯树 + 物料平衡报告。

## 序贯步骤

### 1. platform 物料平台注册 → 下发到业务

- 实施/维护人员在 platform 维护物料分类树、物料信息、单位（[[material-master]]）。
- 通过【下发】将物料推到 MES（产品/原辅包/中间品）和 WMS（货品），落地为**停用态**；业务侧启用后参与流转。
- 业务侧【同步】反向拉取「启用且未同步」的物料。

### 2. WMS 货品入库（创建货品批次 + 货品件）

- WMS 货品管理 → 新增货品批次（签名：操作人）。
- 货品批次字段：批号/原厂批号/生产日期/有效日期/水分%/含量%/报告单编号/放行单编号。
- 货品批次下批量新增**货品件**（件号全局唯一正整数，最大 10 位，超限回 1）；件初始量=可用量，预定量/消耗量为 0。
- 货品入库（库存管理 001）：货品件绑到货位，签名含 接收人+递交人；可选「零头入库」生成单独货品件。

### 3. MES 领料计划预定货品（批记录组件执行）

- 生产批次批记录执行 → 点击「批次量领料」/「物料量领料」/「物料预定」组件字段，进入领料计划。
- **预定暂存物料**：勾选本批次已预定或同部门权限内未预定的物料件，操作人+复核人双签名；物料件预定量↑。
- **预定仓库物料**：
  - 批次量领料：选「该物料及成员物料在仓库中的可用货品批次」，输入计划量；
  - 物料量领料：选「该物料及成员物料的货品」，输入领料量；
  - WMS 校验批次/物料库存满足计划量；签名完成 → 计划人。
- **量值变化**：WMS 货品/货品批次 `可用量↓ 预定量↑`。
- 领料单名称自动生成：`生产批号-两位流水号`（同生产批次下不重复）。

### 4. WMS 仓库发料（货品件消耗）

- WMS 仓库发料列表展示所有待发料的领料计划。
- 选领料计划 → 批次发料/货品发料 → 勾选货品件（仅未预定的可用件） → 完成发料签名（发料人+复核人）。
- **校验**：发料量需满足计划量；货品件需生效；货品/批次库存满足其他领料计划预定。
- **量值变化**：
  - 货品件：`可用量↓ 消耗量↑`（用尽即消耗）；
  - 货品批次：`预定量↓`、可用量按发料量扣减（超出预定时）、`消耗量↑`；
  - 货品：同上汇总。
- **取消发料**：取消人+复核人签名，`预定量↓ 可用量↑`，通知 MES。

### 5. MES 领料接收（货品件 → 物料件 转换）

- 批记录"领料接收"组件 → 选领料单 → 整批接收或物料件接收 → 扫描/选择暂存货位 → 双签名（接收人+递交人）。
- **创建 MES 物料批次**：
  - 同物料类型下同物料批号不重复；存在则追加物料件，不存在则新建。
  - **字段继承**：批号/有效日期/水分%/含量%/原厂批号/供应商/生产商。
  - **原始编码** ← 原货品合并编码；成员货品批次 → 父级物料批次。
- **创建 MES 物料件**（件号按 MES 规则重新生成）：
  - **物料来源** ← 原货品件号（用于全链路追溯）；
  - 初始量=可用量=接收量，预定量=消耗量=0。
- **批量打印标签**（标签字段：物料、物料批号、物料件号、物料量、有效日期、暂存货位 等）。

### 6. 暂存货位库存（物料件入暂存）

- 物料件与暂存货位绑定（[[location-master]]）；后续可进行 入库/出库/移库/盘点/退库/销毁/使用/拆包 等操作。
- 所有操作均产生物料日志 + 货位日志 + 操作日志 + 签名日志。

### 7. 配料称量 / 投料消耗

- 称量执行：[[feature-weigh-center]]、[[flow-weighing-execution]] —— 称量工单生成物料件净量/皮重/毛重。
- 投料组件（生产投料/配料投入/配液投入/物料投入）消耗物料件：`可用量↓ 消耗量↑`。

### 8. 中间品产出 / 成品产出（新物料件回流）

- 中间品产出/配液产出组件创建新物料件（中间品物料），回流到暂存货位；
- 成品产出组件创建成品记录（无物料件号，直接进入批签发流程 [[feature-lot-release-mgmt]]）。
- 这些产出节点构成物料追溯树的"产出"侧。

### 9. 物料追溯与物料平衡

- **物料追溯配置（016）**：按工艺建物料追溯模版，配置追溯树（根节点=产品+工艺；子节点=原辅包/中间品）。
  - 每节点配：物料平衡（展示/不展示）、平衡范围（最小值-最大值，开闭区间可选）、平衡计算（参与/不参与）。
  - 配置节点对应工艺的「消耗信息」「产出信息」的 工序/步骤-任务。
- **物料追溯（012）**：按生产批次展示追溯树（列表 / 图谱 两种视图），含 物料详情、物料谱系。
- **批次追溯（013）**：展示生产批次的批次信息 + 执行信息 + 物料追溯 + 设备使用 + 房间清场 + 检验信息 + 异常信息 + 批记录。
- **物料日志（003）**：操作时间/类型/具体操作/操作人员/物料信息/物料件号/预定量/可用量/质量状态/检验信息 等全字段查询。

#### 物料平衡公式

> **物料平衡 = 当前节点产出量 / 子级中配置为「参与平衡计算」的物料消耗量之和**

- 计算结果为百分比，保留小数点后两位，修约方式：**四舍六入五成双**。
- 子级参与计算的消耗量之和为零时，不展示物料平衡。
- 符合配置的平衡范围 → 绿色；超出 → 红色。
- 暂不区分单位，后续可扩展计算规则。

## 关键分支与异常

- **成员物料混批**：领料计划可选成员物料的货品批次；接收时统一以父级物料创建物料批次；物料预定组件（018）专用于配料混批场景。
- **拆包出库**：物料件部分出库，原货品件留货位，新物料件继承预定信息出暂存。
- **货品件失效**：仓库发料时校验货品件有效性，失效则提示重新选择。
- **领料计划超额**：发料量超过预定时扣减可用量，并校验不影响其他领料计划。
- **无追溯模版**：物料追溯/物料谱系要求生产批次工艺存在启用的追溯模版，否则提示。
