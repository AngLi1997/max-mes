# 合规追溯链端到端流程

> 本页讲**端到端时序**：一次业务操作如何经多重日志落入 111 审计管理中台，最终支撑 GMP 合规审计。
> 横切机制（按钮清单、签名触发点、节点规则）见 [[audit-trail-and-logs]]、[[esignature]]、[[approval-flow]]。

## 流程概述

- **触发条件**：用户在任意业务功能页面执行关键操作——按钮操作（新增/编辑/删除/关联/导出/审批）、签名动作（保存/操作签名/复核签名/数据修订/记录复制/记录作废/计划终止/工序重做/批签发审核）、数据修订、或审批节点流转。
- **输入**：业务操作上下文（操作人、操作对象、旧值新值、签名账号密码、流程实例 ID 等）。
- **输出**：111 审计管理中台可按系统/时间/操作人/签名对象等多维查询的日志集合，支持 PDF 导出。

## 序贯步骤

### 步骤 1. 业务操作触发

用户在业务功能页面执行关键操作。触发源分四类：

- **按钮操作**：按各功能 PRD 末尾的按钮清单埋点（见 [[audit-trail-and-logs]] 的按钮清单模式）。
- **签名动作**：触发签名弹窗，输入账号密码（见 [[esignature]] 触发点表）。
- **数据修订**：在已填报记录上修订值，需操作人 + 复核人双签名，签名对象追加 `-旧值:新值`。
- **审批节点流转**：提交审核、节点处理人审批通过/不通过/退回（见 [[approval-flow]]）。

### 步骤 2. 实时落日志（操作日志 + 签名日志）

业务操作发生后，**实时**写入两条日志维度：

- **操作日志**：记录功能模块、业务操作、操作人（名称+账号）、操作对象、旧值/新值（仅修改操作）、操作时间、备注。
- **签名日志**（仅签名触发点）：每个签名动作产生**两条维度**——操作人一条、复核人一条；签名失败也记录。

> 数据修订场景下，操作日志记录旧值/新值，签名日志的签名对象也追加 `-旧值:新值`，两者通过业务上下文关联。

### 步骤 3. 业务日志落盘（领域专属）

部分业务操作同时触发领域专属业务日志，记录业务实体的量值或状态变化：

- **物料日志**：物料件的量值变化（入库、出库、称量、投料、移库、盘点）。
- **货位日志**：货位状态变化（占用、释放、转移）。
- **称量日志**：称量工单执行记录。
- **清场日志**：工序清场记录。

业务日志在 120-050 生产查询下提供独立查询入口（物料日志 / 货位日志 / 称量日志 / 清场日志），与审计中台并行。

### 步骤 4. 审批流追溯（流程实例节点）

若业务操作进入审批流（如记录审核、工艺审核、配方审核、指令单审核、批记录审核、批签发审核、生产 BOM 审核），流程引擎记录：

- 流程实例的发起人、发起时间、结束时间、结束状态。
- 每个节点的处理人、处理时间、处理状态、处理意见。
- 节点处理规则按或签/会签（人员/角色/人员+角色）区分，以任务节点维度记录每个处理人数据。

详见 [[approval-flow]]。

### 步骤 5. 汇总到 111 审计管理中台

所有日志汇总到 **111 审计管理**（详见 [[audit-trail-and-logs]]）：

- **按系统 tab 切换**：MES / LIMS / 生产App 等。
- **流程树导航**：根节点（全部）→ 流程类型 → 流程名称。
- **查询**：按时间、操作人、签名人、业务实例名称等多维筛选。
- **导出**：登录日志 Excel、操作日志 PDF、签名日志 PDF、审核流追溯 PDF。

### 步骤 6. 签名追溯（独立查询路径）

签名日志提供独立追溯路径，按 **签名对象 / 签名动作 / 签名人** 查询：

- 通过签名对象（如批号-工艺-工序-工序步骤-记录项名称）反查所有签名动作。
- 通过签名人反查其执行过的所有签名。
- 用于精准定位"谁在何时对哪条记录做了什么签名"。

## 关键分支与异常

- **签名失败**：账号密码不一致也记录签名日志，状态标"失败"，便于追溯尝试行为。
- **数据修订**：操作日志的旧值/新值与签名日志的签名对象 `-旧值:新值` 双重记录，确保修订前后可追溯。
- **登录失败**：登录日志记录失败原因（账号密码错误 / IP 限制 / 终端未注册）；**锁屏界面解锁不计入登录日志**。
- **同账号二次登录**：首次登录被自动登出，登出描述记"账号二次登录，自动登出"。
- **查询时间窗口**：所有日志列表初始化展示**近 30 天**；时间筛选最长区间 **30 天**，超出不可查询。

## 追溯用途

- **GMP 合规审计**：药监局检查时按批次/时段导出全套日志 PDF。
- **质量调查**：偏差发生时，反查相关批次的操作、签名、审批流节点。
- **偏差追溯**：从偏差编号出发，串联生产请验/偏差记录、操作日志、签名日志定位根因。
