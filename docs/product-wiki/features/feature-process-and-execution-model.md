# 工艺配置与执行模型

> 工艺是 MES 配置端的**核心聚合点**：以工艺版本为容器，把"产品 + 配方 + 记录 + 产线/房间/设备/班组"组装成可执行的生产工艺流程，并在工序/步骤/任务节点上挂接记录项的组件业务配置（物料限制、允差、数值范围、工位权限等）。工艺既是配置对象，也是执行骨架。
>
> 菜单归属见 [[domain-production-config]]；配方/BOM/记录 实体字段见 [[recipe-bom-master]]、[[record-dataset-master]]；端到端执行时序见 [[flow-batch-production]]。

## 工艺/配方/BOM/记录 四者关系

| 实体 | 回答的问题 | 关键内容 |
|---|---|---|
| 工艺 | **怎么执行** | 工序流程画板 + 步骤/任务节点 + 完成条件 + 房间/设备/班组/产线 |
| 配方 | **用什么物料** | 物料清单 + 数量/单位/精度/修约/折干折纯/允差 |
| 生产 BOM | **称量需求** | 称量需求目标量 + 用途 |
| 记录 | **填什么** | 记录项 + 基础/业务组件 + 公式 |

### 绑定链

```
产品（platform 下发，停用态） → 启用
   ↓ 工艺新增时选择产品
工艺（挂产品 + 1 个启用态配方版本 + 1..N 个非作废记录版本 + 产线）
   ↓ 工序节点勾选配方物料 / 步骤-任务节点挂记录项
工序/步骤/任务节点（实例化记录项组件 + 物料/工位绑定）
   ↓ 生产执行时实例化
生产批次（指令单分解 → 生产前确认 → 工艺工作流启动）
```

- **工艺 ↔ 配方**：1:1（一条工艺版本绑一条启用态配方版本）。
- **工艺 ↔ 记录**：1:N（一条工艺版本可绑多个记录版本，记录项级联选择，已作废版本不可选）。
- **工序 ↔ 物料**：从工艺绑定的配方物料中多选分配给当前工序。
- **步骤/任务 ↔ 记录项**：从工艺绑定的记录版本中选 1 个记录项（单选），可配置"记录复用"。

## 工艺层级与节点类型

```
工艺
  ├─ 工序节点（Process Node）—— 工艺流程画板上的节点
  │    └─ 步骤节点（Step）/ 任务节点（Task）—— 工序流程画板上的节点
  │         └─ 记录项组件实例（基础 + 业务）
  └─ 流程控制器（Gateway）—— 工艺/工序流程画板上的网关
```

工序和步骤/任务**都是画板+抽屉配置**模式：拖入画板 → 点 ⚙ 弹出右侧抽屉配置 功能/执行条件/完成条件。任务节点由"任务库-创建任务"产生，与步骤节点平级。

### 步骤/任务功能类型

| 功能 | 配置记录项 | 配置操作规程 | 支持节点 |
|---|---|---|---|
| 记录作业 | Y（记录复用开关） | Y | 步骤 + 任务 |
| 工序换班 | N | N | 步骤 + 任务 |
| 工艺换班 | N | N | 步骤 + 任务 |
| 工序审核 | Y | Y | 仅任务 |
| 工艺审核 | Y | Y | 仅任务 |
| 辅助记录 | Y（不进归档） | Y | 步骤 + 任务 |
| 请验 | N | N | 步骤 |

## 完成条件逻辑表达式

每个工序/步骤/任务节点都有"完成条件"控制何时视为完成；步骤/任务还有"执行条件"控制能否开始执行。两者结构相同：多个原子条件 + 逻辑表达式。

### 原子条件类型

| 类型 | 字段 |
|---|---|
| 任务节点完成 / 步骤节点完成 | 工序节点 + 任务/步骤节点（级联单选） |
| 设备使用状态 | 设备 + 使用状态（可用/不可用/故障/占用） |
| 房间状态 | 房间 + 房间状态（已清场/待清场/在用） |
| 物料预定量 | 物料 + 校验规则（≥/>/=/≤/<）+ 物料量（按配方物料数量类型与生产批量换算理论量） |
| 配料称量签名 / 中间品产出签名 | 无字段，true 时校验物料件签名完整性，存在未签名物料件则无法完成节点 |

### 逻辑表达式

- 原子条件自动编码 A、B、C…（最多 20 个），删除后字母可重用。
- 表达式支持 `&&`、`||`、`!`，如 `A&&D&&(B||C)&&!E`。
- 默认测试条件为 true；可点【测试】按钮验证表达式语法。
- 节点连入线默认为必要前置（A 连入 B 视为必须完成 A 才能执行 B）。

## 工作流驱动

工艺流程画板与工序流程画板均使用统一工作流模型：

- **节点**：开始节点 / 工序节点（或步骤/任务节点）/ 流程控制器（网关）/ 结束节点
- **流程控制器**：默认"并行"，可切换为"选择"（非必要节点必填，至少选 1 个前置节点）
- **画板交互**：拖入节点 → 节点 4 个锚点（上下左右）连线；开始/结束节点不可删除
- **保存校验**：至少 1 个工序节点 + 每个工序至少 1 个步骤/任务节点 + 节点流入流出完整 + 工序别名/名称在工艺版本内唯一 + 步骤/任务别名/名称在工序内唯一

## 工艺版本状态机

```
                  ┌─── 重新编辑（仅确认态） ───┐
                  ↓                              ↓
新增/复制 → 编辑 ──→ 确认 ──→ 审批 ──→ 待生效 ──→ 生效 ──→ 失效
                  ↑       ↑          (立即生效)↓        ↓
                  │       └─ 审批不通过                     └─ 停用 ─→ 失效
                  └─ 审批退回（首节点不可退，回到编辑）<待核：PRD 未明确退回目标态>
```

| 状态 | 触发 | 可见按钮 |
|---|---|---|
| 编辑 | 新增/复制/升版默认；审批退回回到此态 | 编辑、查看、确认、历史 |
| 确认 | 编辑态点【确认】，校验记录版本为确认态 + 流程完整性 + 记录项匹配；审批不通过回到此态 | 启用、查看、历史 |
| 审批 | 确认/失效态点【启用】，发起启用审批 | 查看、审批进度、历史 |
| 待生效 | 审批通过且选"生效日期"，到日期定时任务转生效 | 查看、停用、立即生效、历史 |
| 生效 | 审批通过选"立即生效"，或待生效到日期，或点【立即生效】；旧生效态自动转失效 | 查看、停用、历史 |
| 失效 | 生效/待生效被停用；或被新生效版本替换 | 查看、启用、历史 |

- **同一工艺全局唯一生效版本**；若已有"待生效/审批"中的版本，无法再次发起启用审批。
- 确认校验：流程完整性（至少 1 个工序节点、每工序至少 1 个步骤/任务、节点连线完整）+ 记录版本为确认态 + 步骤记录项与绑定记录版本匹配。
- 升版时记录及组件的业务配置可继承；归档顺序独立可调整（编辑态可拖动，确认/审批态只读）。

## 移动端执行段（121）

生产前确认 → 工作流启动 → 工序节点按"工艺班次-工序排序-工序班次"升序展示 → 步骤/任务按"步骤/任务排序-节点创建时间"升序展示。数据权限由生产前确认/换班确定的步骤-任务绑定的班组实现。

### 工序级动作

- **终止生产**：操作人签名，流程终止、记录归档。
- **暂停生产 / 恢复生产**：操作人签名暂停/恢复。
- **工序重做**：操作人 + 复核人签名（复核人限当前工序负责人角色，不可与操作人相同），回到工序起点，已完成步骤转进行中。
- **强制完成**：满足工作流走到结束节点但未满足完成条件时，操作人签名后强制完成（按钮有权限控制）。

### 步骤/任务执行 → 业务组件作业

记录作业填报后，进入业务组件作业：

| 业务组件 | 关键动作 |
|---|---|
| 配方信息 | 工序指定配方物料时按指定写入分组；未指定时按配方物料顺序写入 |
| 生产投料 | 扫码/手输物料件号 → 7 步校验（组件物料绑定/有效/有效期/质量状态/预定/出库/已添加）→ 投料量校验 → 设备投入 → 操作人签名 |
| 配料投入 | 与生产投料同构；物料件来源限定为「配料称量产生的物料件」并须先确认配料单/配料计划；6 步校验（同生产投料减"组件物料绑定"）→ 设备投入 → 投料人单签名；物料件状态 待投料→投料中→已投料；完成条件为配料计划下批次全部称量完成且物料件全部已投料 |
| 中间品产出 | 产出人 + 复核人签名 → 产出批次（默认回显最近）→ 选模式（产出称量/手动称量/手动产出/扫码去皮）→ 物料件生效 |
| 成品产出 | 默认回显生产批号 → 单件量+单位+件数 → 操作人签名 → 批量创建成品件 |
| 配液量取 | 操作人 + 复核人双签名 → 选配液单/配液批次 → 添加物料件消耗 → 模式（手工量取/秤具量取，当前版本仅手工量取）→ 量取打码产生未签名物料件；余液量取物料件不预定；与中间品产出共享称量模式 |
| 配液投入 | 与配料投入同构；物料件来源限定为「配液量取产生的物料件」并须先确认配液单/配液计划；6 步校验 → 设备投入 → 投料人单签名；完成条件为配液计划下批次全部量取完成且物料件全部已投料 |
| 配液产出 | 产出人 + 复核人双签名 → 选配液单自动带出产出中间品 → 选模式（手动产出/秤具产出，当前版本仅手动产出）→ 创建中间品批次+未签名物料件；与中间品产出共享产出模式；额外支持「产出作废」双签名 |
| 设备数采绘图 | 设备功能点（[[equipment-master]]）数采值绘图 |
| 检验结果 | LIMS 请验/检验结果回填（[[domain-inspection]]） |

**投料类组件对比**：生产投料（011）/ 配料投入（009）/ 配液投入（021）共享 5 状态机与投料人单签名、量值变化规则（初始量/可用量不变，预定量↓、消耗量↑，容器解除绑定）；差异在物料件来源与上游计划绑定——生产投料消费称量工单/物料称量产出的物料件，配料投入消费配料称量产出物料件并绑定配料单，配液投入消费配液量取产出物料件并绑定配液单。配料投入工位仅来自工序房间下，配液投入工位还可来自工艺产线下。
