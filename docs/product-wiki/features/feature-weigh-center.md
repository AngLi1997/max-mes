# 称量模式实体模型与状态机

> 本页展开称量域内四种称量模式的实体关系、关键状态机与配置要点。
> 域目录与功能清单见 [[domain-weighing]]；端到端执行时序见 [[flow-weighing-execution]]。

## 四种称量模式分工

| 模式 | 入口 | 聚合实体 | 需求来源 | 产出物料件 |
|---|---|---|---|---|
| 称量中心（一代） | 120 称量任务规划 + 121 称量中心执行 | 称量任务（物料+单位+称量中心） | 指令单下发时由物料投入组件配置创建 | 预定到生产批次，默认未签名 |
| 称量工单（二代主线） | 120 称量工单规划 + 121 称量工单执行 | 称量工单（物料批次+单位+称量中心+计划生产日期） | 生产批次配料确认时创建 | 预定到生产批次，默认未签名 |
| 配料称量组件 | 工艺批记录内嵌组件 | 配料计划 + 配料单 + 配料批次 | 配料计划下配料批次的配料量 | 预定到当前生产批次，默认未签名 |
| 物料称量 | 121 移动端独立功能 | 无工单/无批次上下文 | 用户现场手输物料+批号 | 直接创建中间品物料批次+物料件，默认**已生效** |
| 称量数据组件 | 工艺批记录内嵌组件 | 仅采集记录 | 无需求 | 不产生物料件，仅回填 4 字段 |

> 称量中心(一代)的称量模式术语「物料称量」在二代更名为「增重称量」，二者语义一致（相对「手动称量」）。

## 配液子链路（与称量的关系）

配液链路（019 计划 → 020 量取 → 021 投入 → 022 产出）面向半成品配置（如血凝素 33.4μg/ml）与溶液配置（如 95%→75% 乙醇），**独立于称量工单/配料称量组件**（不依赖工单体系、不耦合配料计划），但与称量**共享物料件模型与签名机制**。

### 与称量共享的机制

- **物料件模型**：量取/产出的物料件同样遵循四态量值（初始/可用/预定/消耗），见 [[material-master]]。
- **签名状态机**：量取打码与产出打码产生的物料件默认「未签名」，需操作人+复核人双签名后批量生效为「已签名」（量取）或产出人+复核人双签名（产出）；未签名物料件不可用于配液投入。机制与称量结果页签名一致，详见 [[esignature]]。
- **投料状态机**：配液投入组件复用物料投入的 5 状态机（待投料 → 投料中 → 已投料，失效/未签名为异常态），投料人单签名；投料时物料件初始量/可用量不变、预定量↓、消耗量↑，并解除容器绑定。
- **量取/产出打码**：与称量打码一致，连续 3 次稳定一致读数方为有效；净重必须 > 0；可绑定容器（1:1）、入暂存货位、打印标签。

### 配液特有的子模型

- **浓度求解（独立于重量允差）**：配液计划通过「物料批次浓度参数（物料批次自定义字段）× 配液量 = 目标浓度 × 目标体积」自动求解混批配比，差值按勾选顺序依次消耗各批次物料量，按配方物料精度修约。
- **配液单状态机**：配液计划/配液量取/配液投入/配液产出均以「配液单」为聚合实体（名称 = `生产批号-两位流水号`），各阶段独立切换；不同于称量以「工单/任务」为聚合。
- **配液批次量取状态机**：`未量取 → 量取中 → 已完成`（与称量需求状态机术语不同但形态相近）；余液量取物料件**不预定**生产批次（与余料称量一致）。
- **产出作废**：配液产出独有的「产出作废」操作（产出人+复核人双签名），将未签名的产出物料件转为「已作废」并回退量值、解除容器与货位绑定；称量/中间品产出无对应功能。
- **当前迭代范围**：量取当前仅实现「手工量取」（无秤具），产出当前仅实现「手动产出」；秤具清零去皮打码模式（配液量取/余液量取/配液产出）均为「暂时不做」。

> 配液链路的端到端时序不在本页展开；执行入口与业务组件归属见 [[feature-process-and-execution-model]]。

## 实体关系（核心）

```
称量需求（WeighRequirement）
   │ 生产批次 + 物料批次 + 单位 + 称量中心 + 需求量 + 需求用途
   │ 来源：指令单下发(一代) / 配料确认(二代) / 配料计划(配料称量组件)
   │
   ├─── 称量任务（一代）       按物料+单位+称量中心聚合
   ├─── 称量工单（二代）       按物料批次+单位+称量中心+计划生产日期聚合
   └─── 配料单/配料批次         配料称量组件内嵌

称量工单/任务 1 ──── * 称量需求 1 ──── * 物料件（产出）
                                物料件 1 ──── 1 容器（设备）
                                物料件 1 ──── 1 暂存货位

物料件（MaterialUnit）
   ├ 初始量 / 可用量 / 预定量 / 消耗量（四态量值，见 [[material-master]]）
   ├ 签名状态：未签名 / 已签名
   ├ 预定生产批次：称量物料件预定，余料物料件不预定
   └ 绑定：容器、暂存货位（投料时解除容器绑定）
```

## 关键状态机

### 称量需求状态机

```
       未规划 ──规划到工单──► 未称量 ──首次添加物料件──► 称量中 ──满足目标范围──► 已完成
          ▲                       │                                            │
          │                       │                                            │
          └──工单取消/需求删除────┘                                            ▼
                                                                       已失效
                                                              （超时/批次结束未称量）
```

- **未规划**：需求创建后默认状态；工单取消时未称量需求回退到此状态。
- **未称量**：被规划到工单后；可被工单引用。
- **称量中**：物料批次首次添加物料件后转入，表示该需求正在执行。
- **已完成**：净重满足目标范围（闭区间）即认为该需求称量完成。
- **已失效**：超过需求失效时间仍处于未规划/未称量；或生产批次结束（正常/终止）后未称量需求转为失效。

### 称量任务/工单状态机

```
编辑(中) ──确认──► 待下发 ──下发──► 已下发 ──全部需求完成+所有物料件已签名──► 已执行/已完成
   │                 │
   └──取消───────────┘
```

- **一代称量任务**：`编辑 → 待下发 → 已下发 → 已执行`，存在「确认」环节。
- **二代称量工单**：`编辑中 → 已下发 → 已完成`，省去「待下发」中转态，下发即触发执行。
- 取消前置：工单下若有需求处于「称量中」或「已完成」，不允许取消（不展示取消按钮）。

### 物料件签名状态机（合规关键）

```
未签名 ──称量结果页双签名（称量人+复核人）──► 已签名
```

- 称量打码产生的物料件**默认未签名**（物料称量除外，默认已生效）。
- 物料件签名生效发生在称量结果页面：称量人+复核人各输密码完成电子签名（[[esignature]]），未签名物料件**批量**转为已签名。
- 物料件签名生效才改变物料批次量值：初始量增加、可用量增加（余料物料件）、预定量增加（称量物料件）。
- 未签名物料件不可用于物料投入组件；完成工序/生产批次时校验是否存在未签名物料件（[[feature-process-and-execution-model]]）。

### 物料件投料状态机（下游消费）

```
待投料 ──扫码确认──► 投料中 ──投料签名──► 已投料
                                其他功能使该物料件失效 ──► 已失效
```

## 秤具（设备）模型

| 字段 | 说明 |
|---|---|
| 校准状态 | 已校准 / 未校准（当日有效才算已校准） |
| 校准有效期 | 来自设备校准信息，超期则视为未校准 |
| 称量协议类型 | 梅特勒标准协议 / 赛多利斯 |
| 单位 | 必须与物料需求/配方物料单位一致，否则报错 |
| 称量精度 | 大于配方物料精度时报错（配料称量组件） |
| 称量范围/量程 | 最小量程 ~ 最大量程 |
| 占用状态 | 与移动端建立长链接即占用；批次称量完成或长链接超时自动释放 |

- 秤具来源：称量中心绑定工位下具有「秤具标签」的设备（物料称量/称量数据组件为产线所有工位）。
- 称量数据组件的秤具限制放宽为「"秤具"设备类型的设备」，不要求「秤具标签」。
- 详见 [[equipment-master]]。

## 配置要点

### 称量中心配置（120-020-005）

- 自定义分类树（多级）+ 部门授权（[[data-permission]]）+ 工位绑定（1 工位 ∶ 1 称量中心）。
- 启停：存在未完成物料称量需求（除已完成/已失效）时不可停用。
- 删除：产生过历史数据不可删除。

### 物料投入组件配置（工艺侧）

- 物料来源目前仅「称量中心」，预留「配液中心」。
- 物料需求时间：以批生产计划生产时间 + N 日，生成需求日期。
- 需求失效时间：N 日，到期后未规划/未称量的需求转为已失效。
- 物料汇总分组可绑定配方物料，控制回填数据写入位置。

### 配料称量组件配置

- 配方物料多选（控制可称量物料），工位多选，称量模式多选（配料称量 / 手动称量）。
- 称量模式权限：组件工艺配置 ∩ 用户权限码（[[data-permission]]）。
- 配料计划内未称量的物料批次视为「未完成配料称量」，配料称量组件可选择该配料单。

## 关键规则

### 目标范围与允差计算

- **百分比允差**：下限 = 目标量 − ⌊目标量 × 下限百分比⌋（向下舍入），上限同理，按配方物料精度修约。
- **固定值允差**：下限 = 目标量 − 下限允差值，上限 = 目标量 + 上限允差值。
- **进度条颜色**：低于下限橙色 / 区间内绿色 / 超上限红色；超上限时需走「余料称量超目标量签名」（单签名，权限码控制）。

### 称量打码稳定性校验

- 秤具连续稳定的 3 次一致示数方为有效读数；净重必须 > 0。
- 称量结果必须 ≤ 批次剩余量 + 允差上限，否则提示请添加物料。

### 余料称量强制

- 称量任务/工单下**最后一个**称量需求完成后强制进入余料称量，产出物料件**不预定**生产批次。
- 余料物料件签名生效时初始量与可用量一致（预定量=0）。
