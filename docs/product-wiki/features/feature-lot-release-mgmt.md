# 批签发端到端实体模型与状态机

> 本页展开 [[domain-lot-release]] 的实体关系、状态机与公式规则。菜单目录见域页，端到端时序见 [[flow-batch-production]] 的批签发段。

## 概述

批签发以"**数据集定义数据点 → 模板排版与引用 → 选批次生成 → 审核流流转 → 文件归档**"为核心，覆盖配置端与使用端两侧。三大主体实体：**数据集**（数据点-组件绑定）、**批签发模板**（Excel/Luckysheet 排版）、**批签发记录**（成品批次×模板的实例化产物）。

## 实体关系模型

```
┌────────────┐  1..*  ┌──────────────┐  1..*  ┌──────────────┐
│ 工艺(启用) │ ─────► │  批记录模板   │ ◄──1:1─ │   数据点     │
└─────┬──────┘        │  + 记录项    │        │ (数据集内)   │
      │ 成品关联工艺   └──────────────┘        └──────┬───────┘
      │                                              │ 1:1 绑定
      │                                              ▼
      │                                       ┌──────────────┐
      │                                       │ 批记录组件   │
      │                                       └──────────────┘
      │
      │ 1
      ▼
┌────────────┐  1..*   ┌──────────────────┐
│  成品物料  │ ◄────── │ 批签发模板(版本) │  引用：数据集版本
└─────┬──────┘         │  - Excel 模板    │  拖拽：数据点→单元格
      │                │  - 打印区域      │  多数据源：层级号
      │ 1..*           └──────────┬───────┘
      ▼                           │ 1..*
┌────────────┐                    │
│ 生产批次   │ ◄──── 完成 ────────┤
│ (已完成)   │                    │ 1
└────────────┘                    ▼
                          ┌──────────────────┐
                          │ 批签发记录(实例) │ ──► 提交 ──► 独立审核流
                          │  关联：批次+模板  │
                          │  + 生成的文件流  │
                          └──────────────────┘
                                    │ 审核通过
                                    ▼
                          ┌──────────────────┐
                          │  批签发文件      │ ── 预览/打印/导出 Excel
                          └──────────────────┘
```

### 关键关系

| 关系 | 基数 | 说明 |
|---|---|---|
| 数据集 ↔ 工艺 | N:1 | 一个数据集绑定一个成品工艺（已启用版本）；同工艺不可重复创建数据集 |
| 数据点 ↔ 批记录组件 | 1:1 | 数据点树节点 ↔ 工艺下批记录模板中的组件，双击建立绑定；颜色标识绑定状态（橙色=已关联） |
| 批签发模板 ↔ 数据集版本 | N:M | 模板"引用配置"中选择多个已确认数据集；每数据集树仅可选一个版本 |
| 数据点 ↔ 模板单元格 | 1:N（多数据源）/ 1:1（普通） | 多数据源数据点拖入单元格后赋**层级号**；普通数据点直接拖入 |
| 批签发记录 ↔ 成品生产批次 | N:1 | 一个成品批次在同一模板下产生一条批签发记录（重新生成则覆盖） |
| 批签发记录 ↔ 模板版本 | N:1 | 生成时锁定模板版本号；模板停用受约束（见状态机） |

## 状态机

### 1. 数据集版本状态

```
       新建 / 升级版本                 确认
[编辑中] ──────────► [编辑中] ──────────► [已确认]
   ▲                                          │
   │ 升级版本（回显原版本数据）              │
   └──────────────────────────────────────────┘
                       │
                       │ （早期 PRD 中"启用中/停用"已删除，仅留编辑/确认两态）
                       ▼
                 列表"最新确认版本"展示最高已确认版本号
```

- **编辑中**：可编辑数据点树、绑定组件、配置二次处理公式；仅编辑中版本可同时存在 1 条。
- **已确认**：不可编辑，仅可"升级版本"派生新编辑中版本或"详情"查看。被模板引用的前提。

### 2. 批签发模板版本状态

```
新建/升级         确认          启用
[编辑中] ──► [已确认] ──► [启用中] ◄──┐
                ▲           │         │
                │停用        │        多启用版本并存（不互斥）
                └───────────┘
```

- **多启用版本并存**：同一模板下可同时存在多条"启用中"版本，生成批签发时由用户选择。
- **停用约束**：若某启用版本已被批签发管理引用，且对应批签发记录处于**非"未审核"/非"审核通过"**状态（即审核中/审核不通过流转中），该版本不可停用。

### 3. 批签发记录（实例）状态

```
                  选模板+生成           提交
[未生成] ──► [未审核] ──► [未审核(已生成)] ──► [审核中]
                 ▲                          │
                 │                          ├──► [审核通过] ──► 归档为批签发文件
                 │                          │
                 │                          └──► [审核不通过] ──► 重新生成 ──► 回到 [未审核]
                 │
                 └── 退回（审核流节点级）回到上一节点 [审核中]
```

- **未审核**：列表"批签发生成"按钮激活；生成后"提交"激活、"重新生成"激活。
- **审核中**：按钮切为"批签发详情"，提交/重新生成置灰。
- **审核通过**：进入批签发文件库（120-040-006）；不可再生成。
- **审核不通过**："重新生成"激活，可重选模板版本或仅重新抓取数据，再次提交。

### 4. 审核任务节点（独立审核流）

```
待办 ──审核通过──► 下一节点（或结束 = 审核通过）
   │
   ├──审核不通过──► 流程终止（审核不通过）
   │
   ├──退回────────► 回到上一节点（约束：并行网关/开始节点不允许退回；排他网关按选定分支回退）
   │
   └──转交────────► 转交他人（二期）
```

- 节点级"密码认证"勾选时，通过/不通过/退回前先弹密码框（[[esignature]] 强制签名）。
- 节点级"抄送"勾选时，节点完成后向抄送人发站内消息，可"文件预览"。

## 配置要点与规则

### 数据点二次处理公式

| 类型 | 公式 | 说明 |
|---|---|---|
| 数值修约 | `ROUND(NUMBER, NUM_DIGITS)` | 四舍五入、四舍六入五成双、小数位补零 |
| 日期解析 | `DATE(参数1, 连接符, 参数2)` | 年月日/年月日时分/年月日时分秒互转；连接符支持 `-`、`~`、`_`；格式不匹配由公式自动补齐（如 `yyyy-mm-dd` → `yyyy-mm-dd 00:00:00`） |
| 数值区间 | `CONCAT(MIN(), 连接符, MAX())` | 跨多组件取最小/最大并以连接符拼接 |
| 阈值判断 | `NUMCONFIRM(参数, 判断值(小), 判断值(大))` | 越界数字标红，弹"存在偏差数据，请您谨慎处理"；仅提示，不做业务阻断；影响批签发生成/审核/抄送三处展示 |
| 数学聚合 | `SUM` / `AVG` / `MIN` / `MAX` | 来自平台公式配置，参数为组件引用 |
| 拼接 | `CONCAT` | 字符串拼接 |

**校验规则**：日期公式仅支持日期类型组件；MIN/MAX 仅支持数字类型；阈值公式参数支持负数/小数；单参数仅支持一个组件（更换需先删除）。

### 模板编辑约束

- 已关联数据点的单元格：合并、删除行列、修改单元格内容（含前后空格）均会使该数据点-单元格关联关系**失效清空**。
- "导入模板"按钮在已进行"打印区域/权限/公式/引用配置"任一保存后**置灰**。
- "设置打印区域"为独立模式，进入后其余功能按钮隐藏；支持已设置区域数字递增、返回上一步、清除所有。

### 批签发生成（数据抓取）规则

1. 按成品生产批次关联查询**同工艺下**所有生产批次（含中间品层级）。
2. 多批次按**完工时间顺序**赋层级号 1/2/3…；与数据点层级号逐位匹配。
3. **层级号不匹配处理**：
   - 数据点层级号 > 批次层级号：多出的数据点单元格展示空（`/`，参数配置可调）。
   - 数据点层级号 < 批次层级号：抛异常"批签发文件数据不匹配，请修改数据集后重新生成！（模板生产数据缺失）"，废弃已填充数据，返回列表。
4. 生成过程展示进度提示"正在获取批签发数据,请稍后..."。

### 审核权限与按钮显示

- 菜单权限：进入批签发审核菜单；无审核权限者列表为空。
- 审核权限：拥有者可处理待办。
- 节点按钮：由审核流模型中**分配节点功能**勾选项决定（通过/不通过/退回/抄送/转交）。
- 审核意见：默认填入"审核通过/不通过/退回"，可手动改，≤50 字符；按模型"必填"配置校验。
