# 检验业务域（LIMS 交互）

> 跨 **MES（120）** 与 **LIMS（130）** 的协同域。MES 侧只承担「请验单配置 + 检验结果组件」两个配置/承接功能；检验执行本身在 LIMS 侧独立承载，不在本库范围。
>
> `100-检验管理.md` 为 LIMS 侧系统总览 PRD，0 字节空文件。

## 域职责

在 MES 批记录执行过程中，**按物料发起请验单**到 LIMS，**接收 LIMS 回转的检验结果**并回填到批记录对应字段，作为批签发的质量依据。

## 域内核心设计要点

1. **请验单配置（001）— 模板化字段**
   - 请验单是**模板**，配置完成后**绑定到物料**（原辅包/中间品/成品三页签，一物料只能绑一个请验单，覆盖式绑定）。
   - 字段分两类：
     - **内置字段**（系统内置）：请验单号（执行时自动生成）、指令单编号、生产批号、产线名称、产线编码、生产批量、生产批量单位、物料名称、物料编码、物料批号、取样量、取样量单位、请验人。
     - **自定义字段**：来源字典「请验单自定义字段」，展示「数据标签-数据键值」。
   - 每字段可配：展示名称、是否必填、默认值、序号（上移/下移控制请验时展示顺序）。
   - 启停：启用后已发起过请验或已绑定物料时**不能停用**。
   - 数据权限：本功能无数据权限控制。

2. **检验结果组件（027）— 批记录业务组件**
   - 在批记录中以业务组件形式存在（与领料计划组件同机制，见 [[record-dataset-master]]）。
   - 分组属性为「批次检验结果」，固定字段含 请验单号/物料名称/物料编码/物料规格/物料批号/请验人/请验时间，**支持自定义字段**（数据类型 文字/数值/日期，数据来源「检验结果自定义字段」字典）。
   - 工艺配置中可绑**工位**（多选，来源：工序绑定房间下的工位 ∪ 工艺绑定产线下的工位）；非工位绑定用户无法进入组件作业。
   - **执行**：
     - 进入组件 → 展示当前生产批次已发起请验且非退回状态的请验单；
     - 【请验详情】查看请验信息（生产信息 + 物料信息 + 请验单信息）；
     - 【检验结果】查询 LIMS 回转结果（含 汇总检验结果 + 检项代码/名称/结果/结论 多行），点【确定】**回填到批记录对应字段**；
     - 历史数据可查看，再次进入可覆盖更新。

3. **检验管理（100）— LIMS 侧独立承载**
   - PRD 为 0 字节，LIMS 侧检验执行不在本库范围；MES 只通过「请验单号」关联 LIMS 结果。
   - 在 [[flow-material-flow]] 请验段：物料投料/产出时按请验单模板自动发起请验；在 [[flow-compliance-traceability]] 中通过物料日志的"请验单号"字段串联检验信息。

4. **物料日志承载检验信息（[[domain-production-management]] 120-050-003）**：
   - 物料日志列表含字段：请验单号、报告单编号、检验信息（查看按钮 → 检验详情）。
   - 当前版本未对接检验时，**请验单号/报告单编号** 由物料管理功能手工录入；对接后从请验单回转数据带出。
