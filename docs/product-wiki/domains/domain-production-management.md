# 生产管理域（030 生产管理 / 050 生产查询 / 060 异常）

> 本域是 MES 执行态的"运行中枢"：从指令单创建到班组配置、配料、暂存、异常，再到事后的日志查询与审核进度。
> 配套：配置侧见 [[domain-production-config]]；端到端时序见 [[flow-batch-production]]；日志体系细节见 [[flow-compliance-traceability]]。

## 域概述

- **覆盖菜单**：`120-030 生产管理` + `120-050 生产查询` + `120-060 异常管理`
- **域职责**：将已发布的工艺/配方（[[domain-production-config]]）转化为可执行的批生产作业，覆盖指令单→分解→确认→执行→归档→查询的全链路
- **核心实体**：生产指令单、生产批次、指令单（工序级）、班组、配料计划/生产批次配料、暂存货位/物料件
- **数据权限基线**：以工艺绑定的部门授权过滤；班组、工位、暂存货位均有数据权限；移动端按"步骤/任务绑定的执行班组"可见

## 域内核心设计要点

### 1. 指令单生命周期（关键状态机）

```
新建/批量创建 → 编辑 ─提交审批─► 审批中 ─通过─► 确认
                   │                │
                   │                ├─退回─► 编辑（退回到开始节点不可退）
                   │                └─不通过─► 作废
                   │
                   └─作废（编辑/确认态可作废，已开始生产不可作废）
                          编号追加 -废yyyyMMddhhmm

确认 → 分解：待分解 → 待确认 → 待下发 → 已下发（移动端可见）
                                       └─不下发不可执行
```

- 作废规则：原生产批号 `HL16231101` → `HL16231101-废2312011104`；已开始生产的指令单不可作废
- 审批未通过：工艺版本回退到"编辑"态（详见 [[approval-flow]]）

### 2. 班组模型（MES 自有，非 platform 主数据）

- **峨眉山迭代后范式**：新建班组改为弹窗（仅录名称/编码/部门授权），**先建组后分配人员**；人员增删不受班组启停控制
- **双向绑定**：用户侧"绑定班组"批量授权；班组侧"人员分配"批量勾选；均做部门数据权限过滤
- **班组绑定产线/工位**：用于工序负责人在指令单确认/生产前确认时按产线过滤可选班组
- **执行班组**：工艺步骤级配置，可在指令单确认/生产前确认阶段调整，可选范围为"所有启用班组"
- 启停规则：启用态班组绑定产线后不可直接停用

### 3. 配料双入口

| 入口 | 触发位置 | 数据源 | 输出 |
|---|---|---|---|
| 配料计划组件 | 移动端批记录执行 | 当前工序配方物料 + 当前生产批次预定的物料批次 | 配料单（生产批号-流水号），回填物料汇总分组字段 |
| 生产批次配料 | 网页端独立列表 | 生产 BOM 称量需求 + 暂存间库存批次 | 称量需求 → 称量工单规划 |

配料量计算：`理论量 = 物料量 × (1-水分%) × 含量%`（按折干折纯方式），修约/单位沿用配方物料或生产 BOM 物料配置。详细称量执行链 [[feature-weigh-center]]、[[flow-weighing-execution]]。

### 4. 暂存间与物料件

- 暂存货位配置见 [[domain-production-config]]（配置侧）；实体字段/量值模型见 [[location-master]]
- 物料件量值：`初始量 / 可用量 / 预定量 / 消耗量` 四态；物料批次为同维度汇总
- 物料件号规则：MES 内全局唯一、正整数递增、最大 10 位、超出后从 1 重新生成

### 5. 移动端 MES 待办与生产管理

- 待办聚合"生产前确认"+"步骤/任务"，按当前/计划待办分组（工序计划开始时间当天为界）
- 生产批次数权限：根据生产前确认/工序换班/工艺换班确定的步骤绑定班组实现，"在任意工序/步骤/任务绑定的班组中"即可见该批次
