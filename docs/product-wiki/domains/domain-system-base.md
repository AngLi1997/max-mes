# 系统基础域

> 本域覆盖平台（100）侧的登录门户、消息、字典、权限、参数、应用、标签等横切能力，是所有业务域（[[domain-production-config]] / [[domain-production-management]] / [[domain-warehouse-interaction]] 等）运行的底座。
> 权限模型与数据权限是 [[data-permission]]、[[audit-trail-and-logs]] 的上游来源；编号规则、字典是 [[numbering-rule]] 的具体落地。

## 域职责

为产品族提供：身份认证与会话、组织与权限模型、消息通知、字典与参数、应用版本管理、标签平台。所有功能均**横切多业务系统**，在 platform 层统一管理。

## 域内核心设计

### 1. 登录与会话

- **强制浏览器**：非指定版本浏览器进入时弹框提示下载（web 与 app 双端）。
- **登录方式**：账号 + 密码；密码规则由 [[domain-system-base]] 参数配置统一约束。
- **同账号互踢**：同账号同平台（web）/ 同账号同系统同平台（app）重复登录，仅保留最后登录会话，前者强制下线并提示。
- **账号状态机**：`已激活` / `待激活`（首次登录需改密）/ `密码过期`（有效期到，登录改密）/ `密码锁定`（连续错密码超限，管理员解锁）/ `停用`。
- **锁屏**：web 端 `Ctrl+L` 快捷键（参数配置可改）+ 不活动超时锁屏（参数配置，默认 30 分钟，0=从不）；app 端独立配置，设备锁屏则系统自动锁屏；同账号 web/app 锁屏互不影响。

### 2. 消息中心（三类消息）

| 类型 | 触发动作 | 通知对象 |
|---|---|---|
| **审核类** | 发起审核 / 节点通过 / 节点退回 / 审核不通过 / 审核通过 | 当前/下一/上一节点审核人；整体通过/不通过通知有数据权限的人员 |
| **预警类** | 物料批次近效期 / 物料最低库存 / 物料到期 / 供应商到期 / 标本库存预警 / 血浆库存预警 | 对应预警权限码角色的用户；数据权限见 [[data-permission]] |
| **告警类** | 异常记录（数据超限/生产修订）/ 设备故障（设备调整为故障状态） | 对应异常类型/设备故障告警权限码角色的用户 |

消息行为以**业务主体**（工艺名称+版本号 / 物料合并编码+批号 / 设备编号+名称等）为载荷；审核类携带审核意见与备注。

### 3. 权限模型（六维）

| 维度 | 模型 | 关键规则 |
|---|---|---|
| 用户（user） | 内置 `admin` 超管账号（不展示）；其余手动创建 | 账号全局唯一，创建后不可改；启停时角色/部门解绑 |
| 部门（org） | 自定义组织架构树；父根"佰墨思科技有限公司"由参数配置 | 部门是 [[data-permission]] 的核心维度；提供"部门管理（无数据权限，给人事）"与"部门内部管理（仅看直属+下级）"两个菜单 |
| 角色（role） | 自定义分类树；内置 `admin` 角色（不展示、不可绑用户） | 角色全局唯一；删除后菜单权限解绑 |
| 权限授权（auth） | 系统切换 tab + 菜单权限树（脚本写入）+ 绑定角色树 | 一级菜单不能绑角色；仅二级菜单及功能组能绑角色 |
| 菜单权限（menu_auth） | 来源为「权限授权」配置的范围 | 给二级菜单/功能组分配角色，是用户可见菜单的源头 |
| 工位（station） | 在设备管理系统工位管理；本域通过绑定工位建立作业权限 | 工位与产线/房间绑定，通过产线/房间数据权限决定工位可见性 |

**密码规则**（参数配置统一约束）：字符集（大写/小写/数字/其他，多选）/ 最小密码长度（6-24）/ 密码尝试次数（0-24，超限锁定）/ 历史密码个数（0-6，不可与历史一致）/ 密码有效期（0-999 天，0=永久）。

### 4. 字典与编号规则

- **字典管理**：字典列表（`dict_name` + `dict_code` 全局唯一）+ 数据列表（`label` + `key`，同字典内 `key` 唯一）。内置字典不可编辑/删除。
- **内置字典示例**：`编号规则` / `生产批号编号规则`（产品名称、产品编码、内包规格、包装规格、产品标识、指令单类型、生产阶段代码、产线编码等占位符）/ `指令单号编号规则`。
- 编号规则的具体配置流程见 [[numbering-rule]]。

### 5. 参数配置

- 数据来源：**脚本导入**（前台表头与脚本对应），不在前端新增，仅编辑"值"字段。
- 值类型（决定编辑组件）：`String` / `int/float/double` / `Boolean` / `ENUM` / `json` / `Date`。
- 参数类型：`业务` / `系统`；所属应用：MES / LIMS / WMS / PLAT 等。
- 支持**手动刷新缓存**（前端 + 后端），更新列表与运行时缓存。

### 6. 标签管理（平台化）

- **场景类型**（系统编号 × 场景）：`01 原辅包` / `02 中间品` / `03 暂存货位` / `04 设备` / `05 房间` / `06 皮重`。
- **数据模型**：标签信息表 + 标签字段表 + 业务分类表 + 业务场景表 + 场景关联表 + 绑定信息表 + 外部二维码绑定表。
- **V1.0 / V1.1 双迭代**：V1.0 标签以脚本形式出（无配置页）；V1.1 提供配置页面，可新增/编辑/启停/删除标签（启停走审计）。
- **打印机配置**：移动端"个人中心-打印设备配置"绑定打印机（缓存在端）；网页端打印时弹窗选择打印设备并缓存。
- **审计追踪**：新增/编辑/删除/启用/停用标签均记入审计（记录对象：标签名称、业务类型、业务场景）。
