# 生产配置域

> 120-020 生产配置域是 MES **实施配置端**的核心域，承载药品生产执行所需的全部静态配置对象。这些对象都是"版本化 + 审批接入 + 部门数据权限 + 配置/使用分离"的模板对象，由实施/药企维护人员在配置端创建并发布，由 120-030 生产管理域与 121 移动端执行时引用。
>
> 工艺/配方/BOM/记录 是配置域的四大主轴，模型细节见 [[feature-process-and-execution-model]]。

## 域核心设计要点

1. **版本化配置对象**：配方/BOM/记录/工艺/操作规程/暂存货位/编号规则/公式/流程模型 全部走"草稿→确认→（审批→待生效→）生效/启用"生命周期；同一对象同一时刻只允许一个"生效/启用"版本，旧版本自动转"失效/停用"。详见 [[version-publish-mechanism]]。

2. **审批接入统一**：记录、配方、工艺、操作规程 的"启用"动作**强制走平台审批流**（[[approval-flow]]），审批通过后可选"立即生效"或"指定生效日期"（定时任务转生效）；未配置对应审批流程时启用失败并提示。

3. **部门数据权限**：配方、工艺、记录、操作规程、暂存货位 在新增时**首次保存强制触发部门授权弹窗**，必须选部门才能创建；版本继承父对象数据权限；用户仅能看到本部门（含上级）数据。详见 [[data-permission]]。

4. **配置/使用分离**：本域只产"模板"，禁止任何运行时数据（生产批次、物料件、称量工单）。运行时引用方在 120-030 生产管理、120-040 批签发、121 移动端。引用必须是"确认/生效/启用"态。

5. **工艺是聚合点**：工艺版本挂接 1 个配方版本 + N 个记录版本 + 产线/班组/房间/设备，工序/步骤/任务节点从绑定记录版本的记录项中拉取组件实例做业务配置（物料限制、允差、数值范围、工位权限等）。模型最复杂，单列 [[feature-process-and-execution-model]] 展开。

6. **编号规则驱动**：记录版本号、工艺版本号由系统内置编号规则（初值 10、增量 10、6 位、不补零）自动生成；生产批号、指令单编号由实施通过字典管理绑定到自定义编号规则，支持物料字段（产品名/编码/规格等）作为参数。详见 [[numbering-rule]]。
