# 电子签名机制

> 本页讲**横切机制**：电子签名的类型、触发点表、签名对象拼接规则、第二签名者控制。
> 签名日志的查询/导出入口在 [[audit-trail-and-logs]]；端到端追溯时序见 [[flow-compliance-traceability]]。

## 定义与适用范围

电子签名是 GMP 法规对关键操作的双重复核要求：操作人在系统中对关键动作进行身份确认，并形成可追溯的签名日志。

- **签名类型**：当前仅支持**密码认证**一种（账号密码校验）。
- **适用范围**：生产执行 App 中的保存、签名组件、数据修订、记录复制/作废、计划终止、工序重做，以及批签发审核环节。
- **状态判定**：签名弹窗点击"确定"后触发校验——账号密码一致记录**成功**；不一致记录**失败**。**失败也记录签名日志**，便于追溯尝试行为。

## 机制一：签名触发点表（关键）

| 触发点 | 签名动作 | 签名对象 |
|---|---|---|
| 按钮【保存】 | 记录保存 | 批号-工艺-工序-工序步骤-记录项名称 |
| 组件【操作人签名】 | 操作签名 | 批号-工艺-工序-工序步骤-记录项名称 |
| 组件【复核人签名】 | 复核签名 | 批号-工艺-工序-工序步骤-记录项名称 |
| 按钮【数据修订】-修订人 | 数据修订 | 批号-工艺-工序-工序步骤-记录项名称-旧值:新值 |
| 按钮【数据修订】-复核人 | 数据修订审核 | 批号-工艺-工序-工序步骤-记录项名称-旧值:新值 |
| 按钮【复制记录】-操作人 | 记录复制 | 工序-工序步骤-记录项名称 |
| 按钮【复制记录】-复核人 | 记录复制审核 | 工序-工序步骤-记录项名称 |
| 按钮【记录作废】-操作人 | 记录作废 | 工序-工序步骤-记录项名称 |
| 按钮【记录作废】-复核人 | 记录作废审核 | 工序-工序步骤-记录项名称 |
| 按钮【计划终止】-操作人 | 计划终止签名 | 产品名称-生产批号 |
| 按钮【工序重做】-操作人 | 工序重做签名 | 批号-工序名称 |
| 按钮【工序重做】-复核人 | 工序重做审核 | 批号-工序名称 |
| 批签发审核-【审核通过/不通过/退回】 | 审核签名 | 列表选中行数据 JSON（备注写入审核动作） |

> "操作人 + 复核人"双签名场景下，每个动作产生两条签名记录，操作人与复核人维度分别落日志。

## 机制二：签名对象拼接规则

签名对象以 `-` 为拼接符，按层级拼接业务上下文：

```
[批号] - [工艺] - [工序] - [工序步骤] - [记录项名称]
```

**变体规则**：

- **数据修订**：末尾追加 `-旧值:新值`，记录修订前后的值变化。
- **记录复制 / 记录作废**：从"工序"层级起拼接（不含批号、工艺），因动作发生在工序内。
- **计划终止**：粒度到生产信息层级——`产品名称-生产批号`。
- **工序重做**：粒度到工序层级——`批号-工序名称`。
- **批签发审核**：以列表选中行 JSON 全量存储，备注栏写入"审核通过/审核不通过/退回"。

> 字段为空时签名对象仍按位置拼接（保留 `-` 占位），避免上下文错位。

## 机制三：第二签名者权限码控制

**操作人（第一签名者）**：当前系统登录人。

**复核人 / 递交人 / 领用人（第二签名者）**：可选范围由**权限码配置的角色**控制——

- 早期方案：按"货位绑定的部门下人员"确定可选范围。
- 当前方案：通过权限码绑定角色，第二签名者必须属于配置角色下的人员，**不再依赖货位-部门绑定**。

详见 [[data-permission]]。这一变更使签名权限与业务数据解耦，由统一的角色授权体系管理。

## 关键参数

| 参数 | 作用 | 取值 |
|---|---|---|
| `platform.sys.signature.time-format` | 签名时间格式 | `yyyy-MM-dd HH:mm:ss`（默认） |

签名时间字段格式由此平台参数统一控制，后端获取后传入签名日志。

## 签名日志查询

签名日志统一在 111 审计管理的「签名日志」页面查询（详见 [[audit-trail-and-logs]]）：

- 筛选：系统名称、签名人、时间区间（最长 30 天）。
- 列表：签名类型、签名动作、签名人、签名对象、签名时间、状态、备注。
- 操作：导出 PDF（字段：签名动作、签名人、签名对象、签名时间、状态）、查看详情弹窗。

## 被哪些域/功能引用

- 执行域 [[domain-production-management]]：生产执行中的保存、修订、复制、作废、终止、重做签名。
- 批签发域 [[domain-lot-release]]：批签发审核的通过/不通过/退回签名。
- 称量域 [[domain-weighing]]：称量执行中的操作人与复核人签名。
- 端到端时序：[[flow-compliance-traceability]] 中签名日志作为合规追溯链的一环。
