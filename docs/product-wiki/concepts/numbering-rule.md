# 编号规则引擎

> 本页讲编号规则的统一引擎、属性模型与各业务场景的接入方式。
> 编号规则是 platform 提供的能力，业务系统通过字典数据驱动消费。

## 引擎模型

### 属性类型（4 种）

每个编号规则版本由若干**属性**按顺序拼接组成。属性类型可选：

| 属性类型 | 说明 | 关键字段 |
|---|---|---|
| 流水号 | 自增数字，**唯一**（一个编号规则只能有一个流水号属性） | 起始流水号、最大位数（[1,10]）、增量、是否补零 |
| 常量 | 固定字符串，常用于分隔符"-" | 常量值 |
| 参数 | 来自业务上下文的动态值，来源为字典管理中编号规则字典的数据标签 | 参数名、是否展示 |
| 日期 | 按指定格式取当前日期 | 日期类型（年/年月/年月日/月/日）、日期格式 |

### 流水号规则

- **补零**：默认是。如最大位数 3，起始 1，补零则首号为 `001`，不补零则首号为 `1`。
- **重置属性**：可配置某些属性作为重置触发器。当重置属性值改变时，流水号重置为起始值。
- 日期属性在重置配置中**只能选择一个**。

### 编号预览

属性配置完成后可点击【预览】查看生成的编号样例。

## 版本生命周期

编号规则自身遵循简化版 [[version-publish-mechanism]]：

```
编辑 ──确认──► 确认 ──启用──► 启用（全局唯一） ──停用──► 停用
                  │
              编辑可删除
```

- **多版本**：可存在多个"编辑"状态版本；不校验编辑状态唯一性。
- **启用唯一**：一个编号规则最多一个启用版本；若已有启用版本，再次启用失败提示"编号规则已有启用的版本"。
- **删除**：仅"编辑"状态可删除。
- 升版继承原版本的所有属性配置；规则名称和规则编码不可修改。

## 字典驱动接入（业务侧）

业务系统不直接调用编号规则，而是通过**字典数据**桥接：

| 字典名称 | 字典编码 | 用途 |
|---|---|---|
| 编号规则 | NumberingRules | 通用编号规则字典，定义可用参数标签 |
| 生产批号编号规则 | ProductionBatchNumberingRules | 工艺绑定生产批号规则 |
| 指令单号编号规则 | ProductionPlanNumberingRules | 工艺绑定指令单号规则 |

工艺侧通过【生产批号规则】和【生产计划编号规则】两个列表（位于 120-020-009 菜单）批量或单独绑定编号规则；字典数据 = 编号规则编码。

## 应用范围

| 业务编号 | 编号规则来源 | 说明 |
|---|---|---|
| 指令单号 | 实施自定义，配入"指令单编号规则"字典 | 支持产品/产线/类型等参数 |
| 生产批号 | 实施自定义，配入"生产批号编号规则"字典 | 支持产品/产线/类型等参数 |
| 记录版本号 | **系统内置**，仅流水号：起始 10、增量 10、最大位数 6、不补零 | 每个记录生成一个实例化编号 |
| 工艺版本号 | **系统内置**，仅流水号：起始 10、增量 10、最大位数 6、不补零 | 每个工艺生成一个实例化编号 |
| 操作规程版本号 | 系统内置 | 由 BMOS 平台提供 |
| 领料单号 | 生产批号-两位流水号 | 领料单依附于指令单 |
| 物料件号 | WMS 全局唯一正整数递增，最大 10 位 | 溢出后回到 1 |

## 编号传参（生产批号 / 指令单号）

工艺绑定的编号规则在执行端实例化时，可注入以下参数（来源于指令单上下文 + 物料自定义字段）：

| 数据标签 | 数据键值 | 来源 |
|---|---|---|
| 产品名称 | `productName` | 指令单产品 |
| 产品编码 | `productMergeCode` | 物料合并编码 |
| 内包规格 | `innerPackingSpecification` | 物料 |
| 包装规格 | `packingSpecification` | 物料 |
| 产品标识 | `productMark` | 物料 |
| 指令单类型 | `productPlanType` | 指令单 |
| 生产阶段代码 | `productionStageCode` | 指令单 |
| 产线编码 | `productionLineCode` | 指令单产线 |

## 使用确认机制

编号生成后**未使用**与**已使用**行为不同：
- 生成后未使用：下次业务获取仍是同一编号（如生成了 `A001` 未使用，下次仍取 `A001`）。
- 生成后已使用：下次给新编号（首次使用 `A001`，下次取 `A002`）。

**保存指令单时通知编号规则"确认已使用"** —— 这是关键的状态推进点。

## 工艺侧配置入口

[[domain-production-config]] 下提供两个配置列表：

### 生产批号规则列表
- 字段：产品名称、产品编码、工艺名称、生产批号规则、规则编码
- 操作：【编辑】（单条绑定）、【批量配置】（两步：选规则→选工艺树）

### 生产计划编号规则列表
- 字段：产品名称、产品编码、工艺名称、生产计划编号规则、规则编码
- 操作同上

批量配置支持工艺树展示（产品分类-产品-工艺）。
