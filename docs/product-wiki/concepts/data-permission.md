# 部门维度数据权限

> 本页讲 BMOS 全局**数据权限**的统一规则（以"部门授权"为维度）。
> 与"操作权限"（按钮级，由角色控制）正交：操作权限管"能不能点"，数据权限管"能不能看"。

## 统一模式

- **维度**：以"部门授权"作为数据权限的唯一维度。
- **载体**：业务对象（工艺/配方/记录/操作规程/产线等）通过绑定多个部门实现数据可见范围控制。
- **作用域**：用户进入功能时，列表只展示该用户所在部门（含上级/下级）有数据权限的对象。

## 首次保存授权（强制）

新增工艺 / 配方 / 操作规程 / 记录 / 生产 BOM 等**首次保存**时，强制弹出**部门授权弹窗**，必须选择部门才能点击确定；必须分配部门信息才能创建对象。

- 弹窗展示范围：当前操作人员所在部门、所属上级部门和下级部门信息。
- **新增版本**或**编辑版本**不会触发部门授权弹窗（已存在对象信息）。
- **复制工艺**保存时会触发部门授权弹窗（视为新对象）。

## 部门树勾选规则

- **勾选当前节点**：自动选中上级节点（不选中下级）。
- **取消勾选**：取消当前节点及所有下级节点。
- 一条数据可属于**多个部门**。
- 支持关键字模糊筛选部门信息。

## 版本继承

- 配方版本继承对应配方的数据权限。
- 工艺版本继承对应工艺的数据权限。
- 记录版本继承对应记录的数据权限。
- 操作规程文件版本继承对应文件的数据权限。

> 即：在对象（外层）上配置的数据权限对其所有版本生效；版本不单独配数据权限。

## 数据权限按钮（已有对象的修改）

对象列表提供【数据权限】按钮：
- 弹窗展示**所有部门信息**（不再限制为当前操作人员所在部门树）。
- 勾选规则同上（选中上级、不选下级；取消则取消当前及下级）。
- 一条数据可属于多个部门。
- 确认后记录"绑定部门"的审计追踪。

## 数据权限过滤点

数据权限在以下场景生效（按部门过滤）：

| 场景 | 过滤逻辑 |
|---|---|
| 工艺审批列表 | 仅展示当前用户有工艺数据权限且可审批的节点 |
| 配方审批列表 | 仅展示当前用户有配方数据权限且可审批的节点 |
| 记录审批列表 | 仅展示当前用户有记录数据权限且可审批的节点 |
| 操作规程审批列表 | 仅展示当前用户有文件数据权限且可审批的节点 |
| 工艺配置-配方选择 | 只能选择对应部门下的启用配方 |
| 工艺配置-批记录选择 | 只能选择对应部门下的批记录 |
| 工艺步骤-操作规程选择 | 只能选择对应部门下的操作规程文件 |
| 暂存货位/称量中心 | 按部门过滤可见范围 |
| 部门内部管理 | 仅展示当前用户直属部门及其下级部门的部门/人员信息 |

## 部门管理的数据权限变体

部门管理有两套：

| 菜单 | 数据范围 | 场景 |
|---|---|---|
| **部门管理** | 无数据权限限制，可查看所有部门 | 人事/系统管理员需要全局视角 |
| **部门内部管理** | 仅当前用户直属部门及其下级 | 各部门负责人独立管理本部门 |

两者按钮一致，仅可见范围不同。

## 角色与部门的双向绑定

- **部门→角色**：部门管理中【分配角色】按钮，给部门分配可选角色；该部门下人员的"绑定角色"弹窗仅能选这些角色。
- **角色→部门**：角色管理中【部门分配】按钮，批量为角色分配部门。
- 用户【绑定角色】可选范围 = 用户所属部门已分配的角色集合。

## 第二签名者范围控制

电子签名（[[esignature]]）涉及多角色场景时，**第二签名者范围**（如递交人 / 复核人 / 领用人的可选范围）由"权限码配置角色"控制：
- 角色由权限码（如 `weighing_submitter`、`weighing_reviewer`、`material_receiver`）标识。
- 系统按当前业务上下文（部门、工位、工艺）筛选有对应权限码的角色下的人员作为可选范围。

## 产线数据权限（特殊）

产线管理增加数据权限：
- 新增产线时【部门授权】字段必填。
- 产线列表提供【数据权限】按钮修改绑定部门。
- 影响：工艺配置-产线选择、班组管理-绑定产线**暂不限制**产线数据（与设备/房间等其他维度独立）。
- 用户【绑定工位】时，工位可选范围基于工位所绑定的产线/房间数据权限并集（且以**目标用户**的数据权限为准，不是当前操作人的）。
