# 审计追踪与四大日志体系

> 本页讲**横切机制**：审计追踪的「按钮清单埋点模式」+「四大日志体系」+「111 审计管理中台」。
> 端到端追溯时序见 [[flow-compliance-traceability]]；电子签名机制见 [[esignature]]。

## 定义与适用范围

审计追踪是 GMP / GAMP 5 合规底线：系统中所有关键操作（新增、编辑、删除、关联、导出、审批、签名、审批流节点流转）必须可被监控、可被查询、可被导出 PDF。

- **适用范围**：全产品族跨系统（MES / LIMS / WMS / 生产App / 平台），不限于单一业务域。
- **权限模型**：审计追踪模块**无数据权限**，仅控制页面权限与功能权限；角色为 QA、QC、管理者。
- **查询时间窗口**：所有日志列表初始化展示**近 30 天**数据；时间筛选**最长查询区间 30 天**（开始时间向前或向后不超过 30 天）。

## 机制一：按钮清单埋点模式（关键）

每个业务功能 PRD 末尾必须用**统一表格**声明本功能所有需要埋点审计的按钮，作为审计日志的数据来源契约。`菜单功能.md` 是按钮清单的**总集**。

表格字段：

| 列 | 含义 | 示例 |
|---|---|---|
| 按钮 | 触发审计的界面按钮 | 【新增编号规则】、【编辑】、【启用】 |
| 操作类型 | 枚举：新增 / 编辑 / 删除 / 关联 / 导出 / 审核 | 编辑 |
| 业务操作 | 业务动作语义 | 新增编号规则、启用、绑定角色 |
| 对象 | 操作对象，通常"编码-名称"格式拼接 | 规则名称-规则编码-版本号 |
| 备注 | 多条数据用逗号间隔；批量场景子集括号拼接 | 多条数据用逗号间隔 |
| 特殊说明 | 弹窗确认后记录等触发时机 | 编辑页面保存成功后记录 |

**对象拼接规则**：以 `-` 作拼接符；存在子集数据时（如批量导入、字典下数据），主对象后加括号填入子集，多数据以逗号隔开。例：`字典名称-字典编码(数据标签-数据键值, 数据标签-数据键值)`。

> 早期方案曾用"操作对象 = JSON 字符串后台直存前台直显"，当前以按钮清单模式为准。详见 [[common-interaction-spec]] 与 `菜单功能.md`。

## 机制二：四大日志体系

| 日志 | 记录维度 | 关键字段 | 来源 |
|---|---|---|---|
| 登录日志 | 登录/登出行为 | 账号、昵称(名称)、IP、**登录终端**、登录状态、登录描述、登录时间、登出时间、登出描述 | 登录界面 + 终端注册表 |
| 操作日志 | 关键按钮操作 | 功能模块、业务操作、操作人(名称+账号)、操作对象、**旧值 / 新值**、操作时间、备注 | 业务端按按钮清单埋点 |
| 签名日志 | 签名动作 | 签名类型、签名动作、签名人、签名对象、签名时间、状态(成功/失败)、备注 | 生产执行 App、批签发审核（详见 [[esignature]]） |
| 审核流追溯 | 审批流节点 | 流程类型、流程名称、实例业务名称/编号、发起人、节点处理人、节点处理时间、节点处理状态、节点处理意见 | 流程引擎实例（详见 [[approval-flow]]） |

**操作类型枚举**（操作日志）：`新增` · `编辑` · `删除` · `关联` · `导出` · `审批`。

**登录日志覆盖场景**：登录成功、登录失败（账号密码错误 / IP 限制 / 终端未注册）、正常登出、同账号二次登录自动登出、锁屏切换账号、修改密码返回登录页。**锁屏界面解锁不计入登录日志**。

## 机制三：111 审计管理 = 统一日志中台

**111 审计管理**（系统编号 101，应用 `bmos-audit`）是日志的**统一查询与导出中台**：

- **服务 tab 切换**：按系统 tab 切换数据来源——`MES` / `LIMS` / `生产App` 等；tab 决定流程树与列表的数据范围。
- **数据流向**：各业务功能页面按按钮清单"记录审计追踪信息"是**埋点产出方**；日志汇总到 111 提供**查询 + PDF 导出**能力。
- **审核流追溯树**：三层节点——根节点(全部) / 流程类型 / 流程名称；按 tab 显示选中应用下的流程类型。
- **流程类型清单**（与业务系统对齐）：记录审核、生产 BOM 审核、工艺审核、操作规程审核、指令单审核、批记录审核、批签发审核。
- **节点处理规则**：区分或签（人员/角色）、会签（人员/角色）、会签（人员+角色）；以任务节点维度记录每个处理人数据。

> 111 是查询/导出层，**不做数据权限**，仅控制页面权限与功能权限。各业务功能页面才是埋点产出方。

## 被哪些域/功能引用

- 所有 [[menu-structure]] 下的业务功能：按按钮清单模式在 PRD 末尾声明审计。
- 配置域 [[domain-production-config]]：编号规则、流程配置、配方/工艺/记录/数据集版本按钮均埋点。
- 执行域 [[domain-production-management]]：生产计划、指令单、班组、物料管理按钮埋点。
- 批签发域 [[domain-lot-release]]：批签发审核走审核流追溯，详见 [[approval-flow]]。
- 称量域 [[domain-weighing]]：称量执行按钮触发签名 + 操作日志双重记录。
- 端到端时序：[[flow-compliance-traceability]]。
