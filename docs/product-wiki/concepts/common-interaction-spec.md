# 通用交互与组件规范

> 本页是 BMOS 系列产品**全局默认**的交互与组件规范。若无特殊声明，所有界面均遵守本规范。
> 与具体业务页解耦：业务页只写**偏离**本规范的部分。

## 全局通用规范

### 显示信息
- **用户显示**：`名称-账号`，如 `张三-zhangsan`
- **多数据分隔**：英文 `,`，如 `张三,李四`
- **层级分隔**：`/`，如 `1分类/1-1分类/1-1-1分类`

### 操作反馈（message）
- **位置**：页面顶部居中
- **消失**：3 秒后自动消失
- **模态**：非模态，不影响页面操作
- **覆盖范围**：任何除查询外的操作都展示反馈

提示语规范：

| 操作 | 成功 | 失败 |
|---|---|---|
| 新增 | 新增成功 | 新增失败 |
| 编辑 | 编辑成功 | 编辑失败 |
| 删除 | 删除成功 | 删除失败 |
| 启停 | 启用成功 / 停用成功 | 启用失败 / 停用失败 |
| 导入 | 成功导入 X 条信息 | 导入失败 |
| 导出 | 成功导出 X 条信息 | 导出失败 |

### 启停（Switch + 模态二次确认）
- 启用提示：`是否启用XXX`
- 停用提示：`是否停用XXX，停用后XXX将不再被使用`（按钮用删除按钮颜色）
- 因业务原因不能停用的，确认后给全局提示说明原因

### 删除（模态二次确认）
- 提示：`是否删除XXX，XXX删除后无法恢复，是否删除？`
- **前置约束**：如数据有启停状态，**仅在停用状态可删除**

### 模态对话框
- **不能点击空白处关闭**，只能点按钮关闭/确认

## 基础组件（基于 antd 4.0.7）

### Input 输入框
- placeholder 默认 `请输入`
- 必带 `allowClear`（鼠标移入显示清除图标，移出不显示 —— 与 antd 不同）
- 最大字符 100；超限提示：`输入内容过长，不能超过100字符`

### TextArea 文本框
- placeholder 默认 `请输入`；带 `allowClear`
- 最大字符 200；超限提示：`输入内容过长，不能超过200字符`

### InputNumber 数字输入框
- placeholder 默认 `请输入`

### Select 选择器
- 均带搜索框（模糊筛选）
- 必带 `allowClear`
- 多选回显时通过响应式布局自动收缩

### TreeSelect 树选择
- 均带搜索框、`allowClear`
- 默认展开全部节点
- 搜索时节点过滤显示且**关键字标红**
- 多选回显**只回显叶子节点标签**（与 antd 不同）；多选有 `allowClear`
- 缺省图：无搜索内容 / 树为空时各有缺省

### Table 表格
- **左对齐**（默认）
- 固定表头
- 单列**默认无排序**（有排序时由产品在业务文档指出）
- 单元格长度**可拖动**
- 操作列固定；操作按钮 ≤4 全显，>4 用 `…` 折叠
- 排序：默认按创建时间降序
- **单表单页面**：初始 20 条
- **双表单页面**：上下各初始 10 条
- 页码选项：10 / 20 / 50 / 100 / 200 条/页

## 业务组件

### 自定义树
- **新增分类**：被新增的父节点**自动展开**（无论原状态）；弹窗统一 **560px 宽（M 号）**，推荐高 300px
- **编辑分类**：成功后名称改变；弹窗 560px 宽
- **删除分类**：
  - 删除 a 分类时选中 a，删除后页面刷新、树默认选中【全部】、列表显示全部
  - 删除 b 分类时选中 a，删除后页面不变
  - 删除失败仍停留在原始页面
- **删除校验**：分类下无数据且无子分类
- **排序**：根据创建时间升序（新创建的在后）
- **默认层级最多 7 层**（超过会有特殊提示，业务有特殊需求由产品说明）

### 树形弹出框
- 尺寸：宽 560px × 高 510px（推荐值）
- 滚动条距离搜索和按钮均 16px
- 搜索：节点过滤 + 关键字标红

### 表单弹出框
- M 号宽度 560px，高度自适应，最大 640px
- 超过 640px 出现滚动条（距按钮 16px）
- 输入框/选择框**失焦时进行必填项校验**

## 页面组件

### 三种基础查询界面

| 类型 | 使用场景 | 主要组件 | 默认条数 |
|---|---|---|---|
| 基础查询界面 | 查询类 | 带搜索的表格 | 20 |
| 单列表配置界面 | 基础配置（如物料信息） | 带搜索的表格 + 自定义树/展示树 | 20 |
| 双列表配置界面 | 带版本的配置（如记录配置） | 表格 + 自定义树 | 上下各 10 |

### 初始化规则
- 自动选中树的根节点（全部）
- 树显示一级节点，其余节点收起
- table 显示所有数据

### 新增数据
- 新增的数据**均为停用状态**（若有启停状态），需用户手动启用
- **根节点（全部）下不能新增数据**
- **无效节点下不能新增数据**（哪些为有效/无效由产品在业务文档提出）
- 选择有效节点新增时，"所属分类"自动回填且可改（来源：除根节点外所有树节点）
- 选择无效节点新增时，"所属分类"为空，需用户选择
- 新增成功后页面刷新，显示新增的数据

### 编辑数据
- **仅在停用状态可编辑**（若有启停状态）
- 编辑实例时"所属分类"字段**不可更改**

### 删除数据
- **仅在停用状态可删除**（若有启停状态）
- 选中数据 → 点删除 → 二次确认 → 列表刷新

### 筛选数据
- 输入/选择查询条件 → 点筛选 → 列表显示符合条件数据
- 重置：清空所有筛选项 + 列表刷新
- 默认筛选方式：**模糊筛选**

## 双列表交互范式

带版本的对象（工艺/配方/记录/操作规程）统一采用：
- **上列表**：对象列表
- **下列表**：选中对象的版本列表（无选中时为空）
- 选左侧分类树节点 → 上列表过滤为该分类及子分类下数据
- 选上列表某行 → 下列表展示该对象的版本

详见 [[version-publish-mechanism]] 各业务对象状态机。
